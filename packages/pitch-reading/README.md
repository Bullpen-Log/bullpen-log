# 싱커 공 읽기 — 독립 3D 시제품

2026-10-27. 싱커 앱과 분리한 로컬 시제품입니다. 로그인·운영 DB·카메라·분석 GPU 서버를 사용하지 않습니다. 화면의 3D 렌더링에는 기기의 GPU를 사용합니다.

## 19판 — 실제 속도 접근·물리 화면 크기·실측 구질 참조

공을 보여 주던 직구 비행 시간의 60% 제한을 일반 연습에서 없애고, 모든 구종을 홈 앞 1.5m까지 1× 속도로 재생합니다. 눈 위치는 유지하며 현재 공을 따라 보는 방향만 자동으로 움직입니다. 실제 공 크기를 유지하고 장면 전체의 시야각을 화면의 물리 크기/권장 시청 거리(휴대폰 35cm, PC 60cm)로 계산합니다. 알려진 아이폰은 Expo가 전달하는 모델별 픽셀 밀도를 쓰며, 모르는 브라우저는 추정임을 표시하고 카드 짧은 변(5.398cm)으로 한 번 확인할 수 있습니다. 실제 시청 거리를 자동 측정하는 기능은 아닙니다.

2025-08-15 Statcast의 같은 투수별 네 구종 599구에서 8개 익명 구질 묶음의 항력/횡방향 힘을 추정했습니다. 한 세션은 같은 묶음을 유지하고 구속 변동을 줄입니다. 구속과 원본 3·4 동작에 맞춰 재계산한 합성 궤적이며, 그 선수의 실제 비행 전체나 국내 중고교/KBO 실측을 그대로 재생하지는 않습니다. 이전 엔진 7 기록도 읽고 재채점하지 않습니다.

결과의 느린 공 추적과 실제 속도 1× 재생을 구분했습니다. 싱커 연결: 타격 홈 → `/hitting/read`, 앱 판 12 이상은 `/pitch-reading` 전용 화면입니다. 웹/앱이 동일한 오프라인 HTML을 사용하며 앱은 기기 캐시에 저장하고 로그아웃 때 기록을 분리합니다.

소스 패키지는 싱커 저장소의 `packages/pitch-reading`에 복사하고 뿌리의 `npm run pitch-reading:build`로 양쪽 장면을 갱신합니다. 독립 시제품에서 연결할 때는 `node scripts/sync-sinker.mjs /path/to/sinker`를 실행합니다. 운영 DB와 새 네이티브 패키지는 사용하지 않습니다.

## 18판 — 조건 선택과 네 단계·네 구종

첫 진입에서 우투/좌투 → 우타/좌타 시점 → 중학교/고등학교/KBO/MLB를 선택합니다. 연습 중 카메라·시야각·공 크기는 고정하고 오른쪽 설정 박스는 일반 화면에서 제거했습니다. 양손 모두 직구·커브·슬라이더·체인지업을 사용하며 단계별 구속 범위와 동일 프로필 내 고정 관찰 시간을 적용합니다. 기존 상세 검수는 개발 주소 `/?lab=1`에서 이용할 수 있습니다.

새 기록에는 단계·투수 손·구속 범위·프로필 버전을 추가합니다. 과거 기록은 유지합니다. [단계 근거와 검증 범위](docs/training-level-validation.md)에 자료, 설계 가정, 미완료된 국내 실측/타자 실험을 구분했습니다. **현재 단계는 자료를 참고한 연습 범위이며 실제 타격 실력에 대한 검증을 마친 척도는 아닙니다.**

## 17판 — 투수 모형의 표면과 유니폼 마감

팔·다리의 분리된 원통과 관절 구를 이어지는 둥근 표면으로 교체했습니다. 어깨 뿌리는 몸통 안쪽에 연결하고, 다리는 신발 안쪽까지 이어 발목 틈을 줄였습니다. 몸통과 허리 단면·표면 법선을 정리하고 구형 골반·벨트 돌출을 없앴습니다. 로고와 등번호는 별도 평면 대신 몸통과 함께 휘는 유니폼 텍스처에 넣었습니다. 모자 챙은 짧고 둥글게, 손가락과 글러브는 겹친 조각이 덜 드러나게 마감했습니다.

투구 3·4 관절, 이전 보간, 공 크기·궤적·속도·판정은 유지합니다. 새 기록에는 선택적 `modelVersion: rounded-uniform-2`를 추가하며 기존 기록은 보존합니다. 정면·측면·뒤쪽 18장면과 닫힌 표면·법선·돌출 범위·프레임 간격을 검수했습니다. [모형 마감 검토](docs/pitcher-surface-review.md)에 변경과 확인 범위를 정리했습니다.

## 16판 — 투구폼 보간과 움직이는 공 윤곽

관절 추정값을 모두 통과하던 Catmull–Rom 보간을 가속도까지 연속인 중심형 cubic B-spline으로 바꿨습니다. 원본 샘플과 이벤트 시각은 유지하며 우완·좌완의 자세 변화는 비교 구간에서 최대 약 0.47/0.90cm였습니다. 뼈 길이·손과 공 연결·접지 검증을 유지하고 `motionVersion: sinker-c2-pose-8`로 구분합니다.

렌더링 배율 상한을 1.8×에서 2×로 바꿔 2× 화면의 추가 확대를 없앴습니다. 공 구면 자체는 회전시키지 않고 장식 실밥만 별도 처리하며, 타자 시점에서 날아오는 공은 실밥 깜박임 없이 흰 구면으로 표시합니다. 검수 중 매 프레임 재생 버튼 SVG를 다시 만들던 작업도 제거했습니다. 흐림·잔상·구속 변경은 없습니다. 측정과 한계는 [떨림 검토](docs/jitter-review.md)에 정리했습니다.

## 15판 — 타자 시점의 공 크기와 실제 속도

우타석의 고정 눈 위치·가로 35°와 공 지름 7.32cm를 유지하고 우완·좌완 모두 릴리스 거리, 거리별 화면 지름, 비행 시간과 브라우저 재생 시간을 대조했습니다. 검수의 기본 재생을 **1× · 실제 속도**로 바꿨습니다. 정답 후 ‘타자’를 누르면 같은 공을 처음부터 1×로 재생하고, ‘다시 보기’도 선택한 시점을 유지합니다. 투수 → 홈 공 추적의 슬로 모션은 유지합니다.

작은 공을 감싸던 1px 실밥 선은 투영 지름에 따라 옅어지게 했고, 타자 시점에서는 화면 하단의 장식 그라데이션을 제거했습니다. 다가오는 흰 공이 화면 위치 때문에 어두워지지 않게 했습니다. 흐림·후광·최소 픽셀 크기 강제 확대는 사용하지 않습니다. 수치와 확인 범위는 [타자 시점 크기·속도 검토](docs/batter-scale-speed-review.md)에 있습니다.

## 14판 — 흐림 제거와 구종 궤적 검토

공의 흐림·노출 샘플 메시를 제거했습니다. 선명한 공 하나를 표시합니다. [2025 Statcast 구종별 무브먼트](https://baseballsavant.mlb.com/leaderboard/pitch-movement?year=2025&pitch_type=ALL&min=q)의 좌우·유도 수직 움직임 크기를 참고하여 과장된 횡변화와 커브 낙차를 줄였습니다. 기본 슬라이더는 스위퍼가 아닌 짧은 글러브 쪽 변화로 설정했습니다. 좌완의 팔 쪽 변화 방향도 별도로 확인했습니다.

아마추어 구속에서 동일한 가속도를 유지해 변화량이 커지던 문제를 줄이기 위해 기본 프로필의 공기력 성분을 구속 제곱에 맞춰 조정하고 중력은 고정합니다. 검수 화면의 명시적인 가속도 조절은 수동 설정을 유지합니다. 새로운 엔진 버전은 `synthetic-aero-7-shapes`이며 기존 기록의 궤적·점수는 보존합니다. 측정 기준·전후 수치·제약은 [구종 궤적 검토](docs/pitch-shape-review.md)에 정리했습니다.

정답 후 다시 보기의 마지막 100ms 부근에서 속도가 갑자기 반으로 떨어지던 전환은 80ms 구간의 연속 감속으로 유지합니다. 실시간 공 읽기에는 이 감속을 적용하지 않습니다.

## 12판 — 원본 동작 비교와 릴리스 보정 수정

샘플 3·4의 옆·뒤 원본 영상에서 무릎 들기·착지·릴리스 전후를 추출해 비교했습니다. 영상의 대응 시각은 기존 분석 결과의 `t`·`tBack`을 사용했습니다. 기존의 55ms 손목 보정이 어깨 기준 손목을 원본 분석 관절에서 좌완 최대 22.64cm·우완 최대 26.68cm 벗어나게 만들었습니다.

팔을 공의 발사 속도에 맞춰 끌어당기던 보정을 제거했습니다. 원본 팔·손목·손 방향을 유지하고, 릴리스 위치 차이는 동작 전체의 일정한 이동으로 맞춥니다. 뼈 길이의 미세한 편차만 IK로 보정하고, 발은 마운드에 맞춰 접지합니다. 공만 마지막 6ms 동안 손끝 주변에서 분리해 위치·속도를 비행과 연결합니다. 구속을 바꿔도 팔·몸통 동작은 달라지지 않습니다.

착지 버튼은 각 샘플의 앞발 고정 이벤트(좌완 207, 우완 258)에 맞췄습니다. 최초 접촉 추정 이벤트(175/237)는 별도로 보존합니다. 원본 분석 관절 대비 추가 변형은 같은 비교 구간에서 손목은 수치 오차 수준, 팔꿈치는 우완 최대 0.73cm·좌완 1.18cm였습니다. 실제 영상에 대한 3D 분석 자체의 오차를 의미하는 수치는 아닙니다. 자세한 비교는 [원본 동작 검토](docs/motion-original-review.md)를 참고하세요.

## 11판 — 무작위 순서와 좌완 샘플 3

10구 연습에서 스트라이크·볼이 각각 4~6개인 비율은 유지합니다. 순서는 Fisher–Yates로 한 번 섞고, 연속 판정 제한·재추첨·강제 교대는 사용하지 않습니다. 같은 판정 4연속·5연속도 나올 수 있습니다. 구종은 별도로 무작위 추첨합니다. `practice-sequence.ts`는 해당 판정에 맞는 실제 합성 궤적을 고르며 KBO 정답을 덮어쓰지 않습니다. 기록에는 `samplingVersion: mixed-zone-2-unrestricted`를 저장해 이전 연속 제한 구성과 구분합니다.

좌완은 싱커 3D 동작분석의 **투구 3(실제 좌투)**를 사용하고, 우완 A/B는 투구 4를 유지합니다. 샘플 3의 관절·뼈 길이·준비 시간·착지·릴리스 이벤트를 별도로 적용합니다. 릴리스 기본 위치는 준비된 샘플 3 손 위치 근처인 x=0.60m, y=1.71m, z=2.20m입니다. 짧은 팔을 억지로 늘리지 않도록 좌완 검수 높이 범위는 1.61–1.74m입니다.

중단된 공은 답변 개수에 넣지 않고 같은 차례에 새 공을 생성합니다. 다시 보기는 같은 공을 재생합니다. 좌완은 원래 좌투 샘플의 분석 좌표 정규화를 복원해 표시하며, 우완 샘플 4를 좌우 반전한 동작이 아닙니다. 저장 결과에는 `motionSample`도 남깁니다.

## 2026 KBO ABS 기준

시점은 기존 우타석·눈높이 1.60m·옆 거리 0.70m·홈 뒤 꼭짓점보다 투수 쪽 0.15m·가로 35° 그대로입니다. 180cm 기준 타자의 존만 [2026 KBO 공식 기준](https://www.koreabaseball.com/Kbo/League/GameManage2026.aspx)으로 변경했습니다.

- 중간면 폭은 홈 43.18cm에 좌우 각 2cm를 더한 **47.18cm**입니다. 실제 홈플레이트 자체는 43.18cm를 유지합니다.
- 중간면 하단은 키의 27.04%인 **48.672cm**, 상단은 55.75%인 **100.35cm**, 높이는 **51.678cm**입니다.
- 좌우는 홈플레이트 중간면(z=18.2245m)에서 한 번 확인합니다. 높이는 중간면과 끝면(z=18.4404m)을 모두 충족해야 합니다. 끝면의 x는 판정하지 않습니다.
- [KBO 선수단 안내자료](https://www.koreabaseball.com/MediaNews/Notice/View.aspx?bdSe=11358)의 ABS 상세 그림(5–7쪽)에 따라 공 일부의 접촉도 인정합니다. 끝면은 **하단만 1.5cm 낮춘 47.172cm**, 상단은 100.35cm 그대로입니다. 안내자료 원본은 로컬 `assets-source/kbo/2025-kbo-abs-guide.pdf`에 보관하며 실행 파일에 포함하지 않습니다.
- 공 중심이 각 면에 도달하는 시각을 같은 합성 궤적에서 수치적으로 구합니다. 중간면에서는 실제 공 단면과 사각형의 접촉을, 끝면에서는 높이 접촉을 확인합니다. 경계 모서리도 실제 반지름을 사용합니다. 공 확대 1.8×는 판정에 영향을 주지 않습니다.

`batter-reference.ts`가 치수를 정의하고 3D 존·9분할·판정·오른쪽 위치도·랜덤 코스가 함께 참조합니다. 오른쪽 마커는 중간면 통과 위치입니다. 중간면에 걸쳐도 끝면 높이가 벗어나면 볼이며 결과에 이유를 표시합니다.

새 기록에는 존 버전 `kbo-abs-2026-180-v1`과 `strikeZone`, 판정 면·끝면 하단·공 반지름을 담은 `zoneRules`를 저장합니다. 이전 존으로 남긴 기록의 판정과 점수는 재계산하지 않습니다. 공개된 기준을 합성 공에 적용한 시제품이며 실제 KBO 장비 오차나 비공개 내부 보정은 재현하지 않습니다.

## 구종·스트라이크/볼 판단

궤적 엔진은 후보 코스를 존 안쪽 42%, 경계 부근 28%, 확실히 벗어나는 코스 30%로 생성합니다. 실제 10구 연습은 위 혼합 구성에 맞는 KBO 판정의 공을 선택하므로 최종 코스 분포는 이 후보 비율과 다릅니다. 검수 화면의 수동 코스는 혼합 추첨을 사용하지 않습니다.

화면이 가려지면 **구종 1번 + 스트라이크/볼 1번**을 고릅니다. 순서는 자유이며 첫 선택까지는 변경할 수 있고, 두 번째 선택으로 답을 확정합니다. 이어 투수 쪽에서 홈을 바라보는 공 추적으로 전환해 같은 공을 홈 뒤까지 재생합니다. 궤적이 차례로 그려지고, 존 통과 뒤 판정과 같은 방향의 위치도가 나타납니다. 구종·스트라이크/볼 정답을 따로 저장하고, 대표 점수는 둘을 모두 맞힌 비율입니다. 이전 구종만 기록은 그대로 읽고 구분해 표시합니다.

## 표시 디테일 보완

- 투수 → 홈 공 추적 시점은 유지합니다. 카메라 가까운 궤적 보조점은 반지름 최대 3px로 제한하고 카메라 뒤의 점은 숨깁니다. 실제 공 크기는 바꾸지 않습니다.
- 존의 중간면과 9분할은 더 선명하게, 깊이 선은 옅게 구분했습니다. 통과 위치 링은 실제 공 주변으로 줄였습니다.
- 오른쪽 위치도는 존에 접근하는 마지막 120ms부터 같은 궤적의 공 위치를 표시하고, 홈 통과 판정 후 결과 마커로 바뀝니다. 표시 방향은 3D 추적과 같은 투수 → 홈입니다.
- 다시 보기 시작 시 정답 색·이전 결과 문구·다음 버튼을 정리하고, 통과 후 다시 표시합니다. 재생을 반복해도 기록이 추가되지는 않습니다.
- 첫 답을 선택해 버튼이 다시 그려져도 키보드 포커스를 유지합니다.

## 타자 시점과 구장

손·배트 전경을 제거하고 고정 타자의 눈 위치·시선·실제 거리를 기준으로 맞췄습니다. 투수 상체와 릴리스 구간을 바라보며 공을 따라 자동 회전하거나 확대하지 않습니다. 공은 실제 크기 1×가 기본입니다. 화면은 실제 주변시야나 양안 입체감을 재현하지 않습니다. 화면 밖으로 공이 벗어나면 관찰을 먼저 끝내고 실제 관찰 시간을 기록합니다.

홈플레이트의 뾰족한 끝을 포수 쪽으로 바로잡았습니다. 투수판 앞 가장자리부터 홈 뒤 꼭짓점까지 18.4404m, 홈 앞면은 z=18.0086m이며 공과 가상 존의 도착 기준입니다. 타석 선은 4×6피트와 플레이트 사이 간격에 맞췄습니다. [WBSC 2025–2026 규정과 도면](https://static.wbsc.org/uploads/federations/279/documents/60e117f0-ac48-e8a1-e553-ba9b82400362.pdf)을 참고했습니다. 눈 위치는 규정값이 아닌 위 가상 타격 자세의 고정 좌표입니다.

## 릴리스와 비행 모델

손에 들린 공과 비행 공은 하나의 메시입니다. 팔과 손은 촬영된 분석 관절 궤적을 유지하고, 공만 마지막 6ms 동안 손끝에서 분리됩니다. 손 모델은 공 위치가 아닌 원래 손 방향을 따라 회전하며 릴리스에 맞춰 손가락이 펴집니다.

공은 중력·속도 제곱에 비례하는 항력·속도에 수직인 회전 효과를 480Hz RK4로 적분합니다. 화면은 계산된 경로를 보간하며, 구속·목표 코스를 함께 맞춥니다. 이전 궤적의 기록은 유지하고 내역에 버전을 표시합니다.

## 기반 동작과 구장

사용자가 지정한 **싱커 3D 동작분석 우완 ‘투구 4’·좌완 ‘투구 3’**를 사용합니다. 기존 분석 화면의 `displayTrack`·`mannequinTrack`·인체 부위 방향 보정을 그대로 사용하고, 단위와 축을 시제품에 맞게 바꿨습니다. 기존 CMU 모션은 더 이상 사용하지 않습니다. 앞발 접촉·릴리스는 분석 결과의 이벤트를 사용합니다. 재생 간격도 분석 화면의 시간 추정값을 사용하며, 마지막 촬영 자세에는 서서히 멈춥니다. 무릎을 든 자세부터 릴리스 직후까지인 샘플 범위를 넘어 새 자세를 만들지는 않습니다.

우완 A/B는 투구 4를 공유하며 구종 구성·재생 속도를 달리합니다. 좌완은 별도의 실제 좌투 샘플 3 동작을 사용합니다. 원본과 크게 다른 팔각도를 억지로 만들지 않도록 릴리스 기본 위치를 샘플 손에 맞췄습니다. 팔·다리 길이를 유지하고, 발은 시제품 마운드 경사에 맞춥니다. 공의 궤적과 구속은 여전히 가상 설정입니다.

하늘은 짙은 청남색에 옅은 구름만 남겨 흰 공과 대비되게 했습니다. 투수·잔디·마운드는 중성 백색의 구장 조명과 마운드 스폿 조명으로 밝힙니다. 공에는 후광을 넣지 않습니다. 중앙 검은 스크린·직선 담장·계단식 배경을 없애고, 홈에서 중앙 122m·좌우 파울폴 100m인 곡선 녹색 패딩 펜스에 거리 표시를 넣었습니다. 관중석은 제거하고, 초안처럼 펜스에 SINKER·PRACTICE 표식만 배치했습니다. 철망과 나무는 사용하지 않습니다.

고정 우타자 시점과 타석 확대 화면을 사용합니다. 결과에 `motionVersion`, `cameraVersion`, 시도별 시점 설정·화면 크기를 저장합니다. 기존 결과도 유지합니다.

동작 출처와 변환 범위는 [샘플 3·4 NOTICE](assets-source/sinker/NOTICE.md), 시점 검토는 [타자 시점 검토](docs/batter-view-audit.md)에 있습니다. 원본 영상·개인 라벨·계정 정보는 시제품에 포함하지 않습니다. 운영 DB·저장소는 읽기만 했습니다.

## 구현 범위

- **공 읽기:** 가상 투수 3명 × 2구종. 투수·최대 가림 시간(340/260/180ms)·고정 우타자 시점·공 크기(기본 1×/식별 보조 1.8×)를 선택하고 10구를 판단합니다.
- 투수별 구속 범위·릴리스·가속도가 다르고, 같은 투수/구종 안에서도 제한된 변동이 있습니다. 목표 위치 분포와 투구 동작은 구종별 정답 단서로 고정하지 않습니다.
- 투구 동작 → 릴리스 → 가림 → 구종과 스트라이크·볼 선택 → 존 통과 공 추적 → 판정/전체 궤적 복습. 답변 전에는 궤적선·가상 존·구속·정답을 표시하지 않습니다.
- **궤적 검수:** 구종·구속·릴리스 높이·가로/수직 가속도·9개 도착 위치를 조절합니다. 타자/측면/위쪽 시점과 0.25×/0.5×/1× 재생, 타임라인을 지원합니다. 같은 공은 모든 시점에서 같은 계산 결과를 사용합니다. 검수 모드는 기록을 만들지 않습니다.
- 답할 때마다 localStorage에 부분 결과를 저장하고, 10구 완료 시 같은 세션을 갱신합니다. 최대 30세션, JSON 내보내기를 지원합니다. 진행 중 모드 변경/종료/새로고침에도 이미 답한 공은 보존됩니다. 답하지 않은 공은 저장하지 않습니다. 새로고침 후 세션 이어 하기는 지원하지 않으며 새 세션을 시작합니다.
- 투구 도중 탭 숨김, 큰 프레임 지연(120ms 초과), 가림 지연(65ms 초과), 화면 방향 변경, 안내/내역 열기는 그 공을 무효로 합니다. 이후 새 공으로 시작해 반복 노출이 점수에 섞이지 않게 합니다.

## 물리 모델과 표시 의미

좌표 단위는 미터, 시간은 초입니다. x는 포수 시점 오른쪽, y는 위쪽, z는 투수판에서 홈 방향입니다. 투수판 앞 가장자리부터 홈 뒤 꼭짓점은 18.4404m, 홈 앞면은 z=18.0086m이며 공의 도착 기준입니다. 출발은 익스텐션이 반영된 release.z입니다.

신규 궤적 `synthetic-aero-7-shapes`는 `dv/dt = gravity - k*|v|*v + |v|*(spin × v)`를 사용합니다. g=9.80665m/s², k=0.0065/m이며 spin은 구종별 초기 가속도 설정을 만족하도록 정한 효과 벡터입니다. 회전수 측정값이 아닙니다. 출발 구속을 고정하고 초기 가로·수직 속도를 수치적으로 조절하여 홈 앞면의 목표 코스에 맞춥니다. 렌더링에는 속도 연속인 Hermite 보간을 사용하며, 인위적인 중간 꺾임이나 구간별 가속 연출은 넣지 않습니다.

힘의 방향과 속도 의존성은 [Alan Nathan의 야구 궤적 자료](https://baseball.physics.illinois.edu/trajectory-calculator-new3D.html)와 [Illinois의 항력 설명](https://dynref.engr.illinois.edu/afp.html)을 참고했습니다. 계수는 이 시제품의 합성 설정이며 해당 연구자의 계산기나 실측 선수 궤적을 재현한 것은 아닙니다. 바람·SSW·실밥 자세·항력계수 변동은 포함하지 않습니다. 기존 `synthetic-ca-1` 기록은 원래의 일정 가속도식으로 읽을 수 있습니다.

검수 화면의 **가로/수직 변화**는 초기 속도 방향을 직선 연장했을 때와 홈 평면 위치의 차이입니다. 수직 값에는 중력이 들어 있습니다. Statcast의 IVB나 중력을 뺀 무브먼트와 혼용하면 안 됩니다.

- 실존 투수/Statcast 데이터가 아니라 **설계한 가상 프로필**입니다. 실제 선수 재현을 주장하지 않습니다.
- 기본 공 지름은 7.32cm이며 1×로 표시합니다. 1.8×는 식별 보조용 확대입니다. 가로 35°로 고정한 투영이며 실제 주변시야나 입체감을 대신하지는 않습니다.
- 투수 외형은 코드로 만든 모델이며, 동작은 우완 투구 4·좌완 투구 3의 분석 동작을 가상 프로필에 맞게 조정합니다. 릴리스 시점은 샘플 분석의 이벤트이며 실측 볼 마커의 정답값은 아닙니다. 같은 투수의 구종끼리 동작은 동일합니다.
- 봉제선 회전은 장식으로 모든 구종에서 동일합니다. 구종별 회전·실밥을 읽는 기능은 구현하지 않았습니다.
- 정답률은 선택한 가상 투수·가림 시간·공 크기·타석에서의 결과입니다. 반응속도, 실제 타격 능력, 실제 경기로의 훈련 전이를 검증한 값이 아닙니다. 실제 관찰 시간도 각 시도에 함께 저장합니다.
