# 구종 궤적 검토 — 2026-10-27

사용자 요청에 따라 흐림 효과를 제거하고 구종별 움직임 크기와 방향을 검토했습니다. 투구 3·4 동작, 고정 타자 시점, KBO 존 치수와 판정 방식, 무작위 스트라이크/볼 구성은 유지합니다. 궤적이 바뀌므로 각 공의 판정은 새 궤적의 실제 면 통과 위치로 계산합니다.

## 비교 자료와 측정 기준

- [Baseball Savant 2025 Pitch Movement](https://baseballsavant.mlb.com/leaderboard/pitch-movement?year=2025&pitch_type=ALL&min=q): FF/SI/SL/CU/CH 각 페이지의 `league_break_x_standard`, `league_break_z_induced_standard`와 구속을 확인했습니다. 요약값과 개별 URL은 [참고 수치](../assets-source/statcast/movement-reference-2025.json)에 보관합니다. 좌우 값은 투구 손 기준으로 정규화되어 있어 좌완의 화면 좌표 부호는 반대로 적용합니다.
- [MLB 구종 설명](https://www.mlb.com/glossary/pitch-types): 싱커·체인지업은 팔 쪽, 슬라이더·커브는 글러브 쪽 변화라는 방향을 대조했습니다. 슬라이더는 스위퍼와 구분했습니다.
- [Alan Nathan의 무브먼트 정의](https://baseball.physics.illinois.edu/Movement.pdf): 중력 포함 낙차와 유도 수직 변화를 혼용하지 않으며, 항력 때문에 생기는 초기 직선 대비 차이도 구분합니다.

아래는 같은 릴리스·중앙 코스·기본 구속으로 계산한 **모델의 유도 움직임**입니다. 같은 초기 속도로 발사한 중력+항력만 있는 공과 같은 홈 앞면에서 비교합니다. x는 포수의 오른쪽이 +, y는 위가 +이며 단위는 cm입니다. Statcast 내부 계산을 그대로 재현한 지표는 아닙니다. 앱의 기존 ‘수직 변화’는 중력 포함 초기 직선 대비 값이라 이 표와 다릅니다.

| 프로필 · 구종 | 구속 km/h | 좌우 이전 → 수정 | 유도 수직 이전 → 수정 |
|---|---:|---:|---:|
| 우완 A 포심 | 122 | −17.4 → −19.5 | +55.8 → +40.4 |
| 우완 A 커브 | 98 | +46.4 → +22.6 | −63.8 → −26.3 |
| 우완 B 싱커 | 113 | −78.0 → −38.4 | +17.8 → +18.7 |
| 우완 B 슬라이더 | 103 | +107.9 → +11.5 | −7.5 → +4.8 |
| 좌완 포심 | 117 | +23.2 → +20.9 | +51.6 → +40.2 |
| 좌완 체인지업 | 97 | +91.6 → +36.6 | +16.9 → +12.9 |

포심은 덜 떨어지는 힘을 유지하되 과한 부양을 줄였습니다. 싱커는 포심보다 부양이 작고 팔 쪽으로 더 흐릅니다. 커브는 탑스핀 방향의 추가 낙차를 유지하되 과장된 큰 아치를 줄였습니다. 슬라이더는 글러브 쪽의 짧은 변화와 중력 낙하를 결합합니다. 체인지업은 좌완 팔 쪽 흐름과 느린 속도로 인한 추가 낙하를 결합합니다. 유도 수직이 +여도 실제 공이 위로 솟는다는 뜻은 아닙니다.

## 구현과 확인

물리 적분은 중력·항력·횡력을 480Hz RK4로 계산하고 속도 연속인 보간으로 표시합니다. 중간에 갑자기 방향을 꺾거나 늦게 추가 힘을 켜는 연출은 사용하지 않습니다. 기본 가속도의 공기력 성분은 프로필 중간 구속 대비 구속 제곱으로 조절하고 중력은 고정합니다. 무작위 변화도 중력 전체가 아닌 공기력 성분에 적용합니다. 80/150km/h 검증에서 같은 프로필의 횡변화가 10% 이내로 유지되고 전 구간에서 올바른 쪽으로 연속해서 휘는지 확인합니다. 검수 화면에서 사용자가 직접 지정하는 가속도는 수동 실험값으로 유지합니다.

엔진은 `synthetic-aero-7-shapes`로 구분합니다. 이전 aero-6를 포함한 저장된 공의 속도·가속도·공기력 값과 점수는 재계산하지 않습니다. 흐림 메시와 노출 계산을 제거했고, 결과 다시 보기의 연속 감속은 유지합니다.

MLB 평균을 참고해 **방향과 크기를 조정한 가상 아마추어 프로필**입니다. MLB의 구속을 그대로 복사하지 않았으며, 실측 아마추어 평균이나 특정 선수의 공을 재현한 것은 아닙니다. 회전수·SSW·바람·실밥 자세는 검증 범위에 포함하지 않습니다. 타격 능력이나 실제 경기 전이의 검증을 뜻하지 않습니다.
