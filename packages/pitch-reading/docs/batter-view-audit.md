# 타자 시점 검토 — 2026-10-27

## 화면에서 바꾼 것

- 투수판 앞 가장자리를 z=0, 홈 뒤 꼭짓점을 z=18.4404, 홈 앞면을 z=18.0086으로 맞췄다. 홈의 뾰족한 끝은 포수 쪽을 향한다. 거리·홈·타석 치수는 [WBSC 2025–2026 규정](https://static.wbsc.org/uploads/federations/279/documents/60e117f0-ac48-e8a1-e553-ba9b82400362.pdf)을 기준으로 확인했다.
- 고정 카메라는 우타자 x=-0.70, 눈높이 y=1.60, 홈 뒤 꼭짓점에서 투수 쪽 0.15m인 z=18.2904이다. 눈높이·옆 거리·앞뒤 위치·타석 선택 입력을 제거했다. 기준 타자의 고정 자세이며 모든 선수의 눈 위치라고 주장하지 않는다.
- 시선은 투수 상체와 릴리스 구간 (0, 1.75, 1.10)을 향한다. 공이나 투구별 출발점에 따라 카메라가 자동 회전하거나 확대하지 않는다. 머리·눈의 실제 추적은 없다.
- 가로 시야각은 35° 고정이다. 세로 시야각은 화면 비율에 맞춰 계산한다. 35° 자체를 인간의 실제 전체 시야라고 간주하지 않는다. 화면 크기를 바꿔도 가로 35°를 유지한다. 화면 거리 보정 입력은 제거했다.
- 휴대폰 가로 타석 모드는 조작부를 112px로 줄여 투구폼을 보는 공간을 늘렸다. 844×390에서 답변 버튼이 화면 안에 있는 것을 확인했다. 좁은 화면에서 공 전체가 벗어나면 먼저 가리고 그 시점을 관찰 종료로 기록한다.
- 공은 지름 7.32cm 기준 1×가 기본이다. 1.8×는 선택 가능한 식별 보조 모드다. 손·배트 모델과 옵션은 모두 제거했다. 전경 장식 없이 투수와 공을 본다.

## 2026 KBO ABS 존과 고정 시점

180cm 타자와 기존 타자 카메라는 유지했다. 존은 [2026 KBO 공개 ABS 기준](https://www.koreabaseball.com/Kbo/League/GameManage2026.aspx)을 적용해 폭 47.18cm, 중간면 하단 48.672cm, 상단 100.35cm이다. 실제 홈플레이트 폭은 43.18cm이며 존만 좌우 각 2cm 확대한다.

좌우는 중간면(z=18.2245m), 상하는 중간면과 끝면(z=18.4404m)을 모두 확인한다. KBO 선수단 안내자료의 ABS 상세 그림(5–7쪽)은 공 일부의 접촉도 인정하며 끝면에서는 하단만 1.5cm 낮춘다고 명시한다. 따라서 끝면 하단은 47.172cm, 상단은 중간면과 동일하다. 끝면 x는 판정하지 않는다.

3D 격자는 중간면에 놓고 끝면 경계는 옅게 표시한다. 오른쪽 위치도와 3D 결과 링은 중간면의 공 중심 위치다. 끝면 높이 때문에 볼이면 그 이유를 표시한다. 실제 반지름으로 경계와 모서리 접촉을 확인하고 1.8× 확대는 판정에 영향을 주지 않는다.

카메라 버전과 가로 35°는 그대로이며 새 존 버전은 `kbo-abs-2026-180-v1`이다. 세션에 존 치수·중간면·끝면·끝면 하단·공 반지름을 저장한다. 이전 판정과 점수는 그대로 보존한다. 공개 기준을 합성 궤적에 적용한 것이며 실제 KBO 장비의 오차나 내부 보정까지 검증한 것은 아니다.

## 투구폼 검토

사용자가 지정한 싱커 3D 분석 우완 투구 4·좌완 투구 3을 가져와 기존 분석 화면의 관절 보정·떨림 보정·부위 방향을 재사용했다. 이전 CMU 캡처는 사용하지 않는다. 동작은 무릎 든 자세부터 릴리스 직후까지인 원본 범위이며, 분석의 착지·릴리스 이벤트와 표시용 시간 추정을 사용한다. 마지막 촬영 자세에 부드럽게 멈춘다. 릴리스 정렬은 동작 전체의 일정한 이동으로 맞추고, 팔과 손 방향은 원본 분석 궤적을 유지한다. 공만 마지막 6ms 동안 손끝에서 분리되며, 고정 길이 팔·다리와 접지 보정을 사용한다. 좌완은 실제 좌투 샘플 3의 준비 시간·관절·착지·릴리스 이벤트를 따로 사용한다. 샘플 4를 좌우 반전하지 않는다.
정면·측면·뒤쪽에서 무릎 들기, 착지, 릴리스, 팔로스루를 확인하고, 타석에서는 우·좌타석과 전체 동작 재생을 확인했다. 자동 검증은 모든 투수의 손-공 연결, 팔 길이, 릴리스 전후 급격한 위치 변화, 몸통-골반 연결을 포함한다. 수학적 연속성 검증만으로 실제 투구 메커니즘의 타당성을 보증하지 않는다.

원본 영상과 보정 전후의 추가 변형 비교는 [원본 동작 검토](motion-original-review.md)에 정리했다.
