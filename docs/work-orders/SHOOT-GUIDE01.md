최신 지도 컴포넌트는 가벼운 격리 서버의 Chromium에서도 다시 검사했다. 실제 React 초기 연결을 일부러 늦춰 활성화 전에는 버튼이 잠기고, 활성화 뒤 한 번 누르면 다음으로 이동하는 것을 확인했다. 실시간 체크가 커서를 바꾸지 않았고 새로고침 시 같은 운동이 열렸다. 새 브라우저에서도 저장 대역의 사유가 보였고 독립적으로 이동했다. 인스타그램 링크만 있는 경우의 안내도 확인했다. 명령 `node /tmp/sinker-shoot-guide-evidence/guide-browser.cjs`는 종료코드 0이며 `guide-browser-final.log`에 남겼다. 전체 Next 격리 흐름의 앞선 통과 뒤 다시 실행할 때는 초기 조작 사례와 시험 서버 시간 초과를 재현했다. 최신 코드는 준비 상태 표시와 현재 운동 복구를 보완했으며, 최신 전체 Next 흐름 재실행은 시험 서버 시간 초과로 완료하지 못했다.
