# 김민님께 — 싱커·덕아웃 Apple 배포 인계 요청

보낸 사람 금윤호 · 2026-11-16. 앞으로 싱커와 덕아웃 iOS는 **금윤호가 Account Holder인 팀**에서 배포합니다. 김민님은 본인 Apple Account로 초대받아 개발·테스트·미국 출시 준비를 함께 맡아 주세요. 우선 아래 두 앱의 현재 상태를 확인해 주시면 금윤호가 기존 설치를 유지할 수 있는 전환 방법을 결정합니다. [금윤호 측 진행 순서와 앱별 결정표](../releases/ios-apple-distribution-ownership.md)

## 지금 부탁드리는 확인

1. 현재 접근 가능한 App Store Connect에서 팀을 고른 뒤 **Apps → 앱 → App Information**, **App Store 버전 이력**, **TestFlight**를 각각 확인해 주세요. 싱커는 예전 이름 ‘Bullpen Log’도 찾아 주세요. 덕아웃은 기록된 숫자 ID가 `6826576447`입니다. 앱이 안 보이면 접근 가능한 팀과 앱 권한을 먼저 확인하고, 보유자만 볼 수 있는 항목은 ‘보유자 확인 필요’로 적어 주세요.
2. 각 앱의 과거 **정식 출시 버전과 국가**를 기록해 주세요. 정식 출시가 없고 베타만 운영했다면 ‘TestFlight만’, 처음 만든 레코드라면 ‘빌드 업로드 없음’으로 구분해 주세요. GitHub에는 두 앱의 TestFlight 업로드 성공 기록이 있습니다. 설치·심사·판매자 확인은 콘솔 표시를 기준으로 합니다.
3. 기존 팀 보유자에게 이전 가능 여부와 필요한 기능을 확인해 주세요. 싱커 본체·휴식 위젯 확장·푸시, 덕아웃 카카오 지도, 로그인·키체인·App Groups·Apple 로그인 등 실제 서명 및 외부 서비스 등록 상태를 대조해 주세요. 각 앱에 실제로 쓰는 것만 표시하면 됩니다.
4. 기존 베타 사용자가 휴대폰 안에만 보관하는 영상·초안이 있는지, 재초대와 별도 설치 시 무엇을 보존할 수 있는지 알려 주세요. 팀·앱 식별자 확인이 끝나기 전에는 기존 베타와 자동 업데이트 경로를 그대로 두세요.

## 경로 결정 후 역할

- **금윤호**가 멤버십과 판매자 표시를 확인하고 김민님을 Users and Access에서 초대합니다. **김민**은 본인 계정으로 수락하고 두 앱의 표시 여부와 필요한 작업 권한을 확인해 주세요. 개인 팀에서 초대된 사용자의 서명 리소스 접근 제한은 금윤호가 맡습니다.
- **공식 이전**을 택하면 기존 팀 Account Holder가 시작하고 금윤호가 수락합니다. **새 앱**을 택하면 금윤호 팀에서 식별자·새 레코드를 만든 뒤 김민님이 베타 재초대와 미국 스토어 준비를 맡아 주세요. 기존 테스터 정리와 배포 키 교체는 앱별 경로와 전환 일정을 정한 뒤 진행합니다.
- 두 앱이 같은 배포 키 설정을 쓰므로 하나만 전환할 때는 다른 앱의 빌드도 영향받는지 먼저 확인해 주세요. 새 팀 TestFlight에서 앱별 빌드 번호, 기존 설치 업데이트 또는 새 설치 결과, 실제 iPhone 확인 결과를 금윤호에게 전달해 주세요. 정식 출시 결정은 별도로 합니다.
