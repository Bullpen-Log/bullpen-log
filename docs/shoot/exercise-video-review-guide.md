# 운동영상 순차 검수 — 김민·금윤호 공통 사용법

2026-11-09 · 금윤호 GPT 전체 총괄. 실제 `03 · 운동영상` GPT 세션의 사용자 지시·진행 기록을 확인해 정리했다. 별도 검수 앱/서버가 구현된 것이 아니라 **기존 라이브러리 + GPT의 브라우저 보조 + 사람 판정 + 세션별 기록**으로 운영하는 방식이다.

**2026-11-10 업데이트:** 담당 분류로 범위를 분리하고, 매 영상마다 GPT가 영상·설명 수정 후보(없으면 확인 범위 내 없음)를 먼저 안내한다. 촬영 필요 항목은 자동 기록하고, 한국·미국·일본별 표현·안전·효능 주장·권리 검토 사항을 분리한다. 사용자 수정 지시가 없으면 변경하지 않는다. 기존 검수 기록은 보존하고 새 규칙을 덧붙이며, 처음부터 재시작하지 않는다.

## 1. 작동 구조

`담당 분류·기존 진행 확인 → GPT가 영상 하나 열고 촬영 여부 자동 기록 → GPT가 영상/설명 수정 후보와 국가별 쟁점 안내 → 사람 직접 시청·판정 → 제안/지시를 구분해 저장 → 명시적인 다음 지시 → 다음 영상`

전체 검수 뒤에는 `수정/편집/재촬영/촬영 필요 목록 → GPT 정리·설계 → 사용자 방향 확인 → Claude에 구체적 발주 → GPT 검수 → 전체 총괄 최종 승인 → 승인 범위 내 반영`으로 이어진다. 영상 검수 자체는 GPT와 사람이 하고 코드 구현은 Claude가 맡는다. 콘텐츠 수정과 운영 반영도 별도 승인 범위를 따른다.

## 2. 김민이 시작하는 방법

1. 자신의 GPT 개발 세션에서 이 문서와 `docs/WORKFLOW.md`, `docs/SESSION_COORDINATION.md`, 관련 HANDOFF를 읽게 한다. 아래 시작 지시문을 보내면 된다. 기존 세션을 재사용해도 된다.
2. **담당 분류만 선택한다.** 김민은 **워밍업 → 상체 → 하체 → 모빌리티**, 금윤호는 **파워 → 코어 → 암케어 → 회복보강**이다. 예전의 금윤호 전체 목록 검수 안내는 이번 사용자 정정으로 대체됐다. 다른 분류가 나타나면 진행하지 말고 필터·목록을 바로잡는다. 별도 암케어 영상의 김민 담당과 운동 분류 암케어의 경계는 미확정이므로 자동으로 합치지 않는다.
3. 기존 [운동 라이브러리](https://dugout-baseball.com/library/training)를 **화면에 보이는 오른쪽 브라우저**로 연다. 로그인·권한이 필요하면 기존 계정으로 접근한다. 다른 컴퓨터의 로그인이나 탭·검수 기록이 자동 공유된다고 가정하지 않는다.
4. 분류·목록 표시 순서대로 목록을 잡는다. 가능하면 운동 ID와 영상 버전/파일 식별자를 함께 기록한다. 같은 운동이 여러 분류에 있으면 중복 표시하되 같은 영상을 완료 건수에 중복 산입하지 않는다. 영상이 바뀌면 재검수 여부를 표시한다.
5. 첫 운동을 열고 플레이어·제목·설명과 실제 재생이 보이는지 확인한다. 문서 페이지를 열었거나 썸네일을 봤다는 것만으로 영상 표시 완료라고 하지 않는다. 오른쪽 표시를 지원하지 않는 환경은 실제 사용할 수 있는 브라우저 창/링크를 안내한다.
6. 한 영상씩 검수한다. 확인할 때까지 자동으로 다음으로 넘기지 않는다.
   - **현재 영상은 끝나면 처음부터 자동 반복 재생한다.** 다음 운동으로 자동 이동시키는 기능과 구분한다. 사람이 일시정지·재생을 조작하는 것은 그대로 허용한다.
   - 운동영상 검수 세션에서 확인한 YouTube 임베드 설정 경로는 **재생 설정 → 옵션 더보기 → 연속 재생 켬**이다. 메뉴 이름만 보고 설정 완료라 하지 말고 현재 영상이 끝난 뒤 처음부터 다시 재생되는지 확인한다. 다른 플레이어나 메뉴가 다르면 실제 반복 기능을 확인하고 불가하면 그대로 알린다.
   - **영상을 새로 열거나 바꿀 때마다 반복 설정과 실제 재생을 다시 확인한다.** 한 번 켠 설정이 모든 영상에 유지된다고 가정하지 않는다. 영상 종료·반복 횟수·시간 경과는 다음 영상 이동 승인이 아니다.
7. 매 영상에서 GPT는 `직접 촬영 여부 → 영상 수정/편집 후보 → 설명 수정 후보 → 국가별 검토 필요 사항 → 사용자 판단 대기` 순서로 짧게 안내한다. 없으면 '확인한 장면/설명 범위에서 특정한 수정 후보 없음'이라고 한다. 전 구간을 보지 않고 영상 전체 정상이라고 말하지 않는다.

## 3. 검수할 때 쓰는 말

| 사용자 말 | GPT가 할 일 |
|---|---|
| 오케이 / 다음 | 현재 영상의 검수 결과를 기록하고 다음으로 이동. 영상 승인과 편집·배포 승인은 구분 |
| 5초 부분 편집 필요 | 운동·시간대·사용자 원문을 메모하고 현재 영상 유지 |
| 반영 / 이것도 반영해줘 | **검수 중에는 요청 기록만** 한다. 즉시 영상·설명·DB를 고치거나 업로드하지 않음 |
| 설명 수정 필요, 다음 | 의견을 기록하고 다음으로 이동. 즉시 수정하지 않음 |
| 판단 보류, 다음 | 보류 사유를 기록하고 다음으로 이동. 보류를 합격으로 처리하지 않음 |
| 다시 보여줘 / 이전 영상 | 해당 영상으로 돌아가기. 기존 판정과 기록 보존 |
| 영상이 안 보여 | 현재 번호 유지, 브라우저 표시·플레이어·재생 상태 확인 후 복구 |
| 오늘은 여기까지 | 현재 영상·완료 목록·대기 의견·다음 위치를 저장하고 종료 |
| 전체 검수 끝, 정리해줘 | 최종 목록을 정리. 자동 편집·업로드·DB 수정은 하지 않음 |

의견만 있으면 진행 승인으로 간주하지 않는다. '오케이'라고 했더라도 이미 남긴 수정 요청을 지우지 않는다. **다음으로 가는 승인과 설명/영상 수정 승인도 다르다.** GPT 제안에 사용자 지시가 없으면 후보로만 남긴다. 모호하면 현재 영상을 유지하고 의미를 확인한다.

## 4. 영상 한 개에서 볼 항목

- **내용 일치:** 제목·시작 자세·동작 순서·도구/밴드 위치·좌우·횟수/버티기와 실제 시범이 맞는가.
- **촬영/편집:** 머리·손·발·도구가 잘리지 않는가, 관찰할 부위가 보이는가, 불필요한 대기/카메라로 걸어오는 장면이 있는가.
- **설명:** 받침과 손발 이동, 호흡, 흔한 실수와 중단 안내가 실제 영상과 맞고 이해 가능한가.
- **재생:** 영상 없음/실패/로딩과 정상 재생을 구분하고 필요하면 1배속 전체 시청 후 특정 구간을 다시 본다.
- **반복:** 현재 영상의 종료 후 처음으로 돌아와 다시 재생되는지 확인한다. 운동영상 세션은 현재 플레이어에서 반복 활성·재생 중 상태와 종료 후 처음으로 복귀를 확인했다고 보고했다. 이 결과를 김민의 별도 브라우저나 모든 영상에서 검증한 것으로 간주하지 않는다.
- **직접 촬영 여부:** 직접 촬영 영상 있음 / 참고 영상만 있음 / 재생 영상 없음 / 출처 확인 필요를 구분한다.
- 버티기·느린 내리기·캐리는 움직임이 작아도 운동 구간이다. 자동으로 빈 시간이라고 판정하거나 자르지 않는다. 실제 영상과 설명만으로 의학적 안전성·효능·이용권을 확정하지 않는다.

GPT가 앞서 찾은 불일치나 의심 장면은 **그 운동 차례에** 함께 설명한다. `GPT 관찰/후보`와 `사용자 판정/수정 요청`은 별도로 기록한다. 장면 일부 확인과 전 구간 시청도 구분한다.

### 운동별 학술 근거 검수 (2026-11-10 추가)

매 운동의 수정 후보를 제시하기 전에 국내외 학술 논문과 공식 학회 자료를 검색·확인한다. 가능한 원저와 체계적 문헌고찰을 우선하며, 최신 공식 지침도 함께 검토한다. 운동 목적·운동역학·실제 동작·중량·세트·횟수·휴식에 관한 설명과 처방을 근거에 대조하고 구체적 수정안을 제시한다. 검색 결과 제목만으로 결론을 확정하지 않는다.

- 연구 대상의 성인/청소년·훈련 수준, 장비와 운동 변형(예: 일반 벤치프레스와 벤치스로우), 부하 산정 기준을 구분한다.
- 급성 출력 측정과 장기 훈련 효과, 일반 파워 향상과 투구 구속으로의 전이를 구분한다. 다른 운동이나 다른 대상의 연구로 현재 운동의 최적 수치를 확정하지 않는다.
- 직접 근거가 없거나 원문/방법·결론을 확인할 수 없으면 그 한계를 기록한다. 임의의 최적 중량·세트·횟수·휴식이나 구속 향상 보장을 만들지 않는다. 확인 가능한 근거 범위의 제안과 추가 검토 필요를 구분한다.
- 기록에는 출처 링크·논문/자료 식별자·연도·확인일, 대상·조건·주요 결론, 현재 운동에 적용 가능한 범위와 적용 불가/불확실한 부분을 남긴다. 앱의 설명문에 논문 목록을 나열할 필요는 없지만 검수 근거는 추적 가능하게 보존한다.
- 근거에 따른 수정안도 **GPT 후보**다. 사용자 지시와 구분해 기록하고, 실제 적용은 전체 검수 후 변경안 제시와 사용자 승인을 거친다. 국가별 법률·권리·표현 검토를 학술 검색으로 대체하지 않는다.

### 한국·미국·일본 출시 검토 기록

사용자가 국가별 법률 문제까지 검토하도록 추가 지시했다. 각 영상의 효능·안전 표현, 설명과 시범의 불일치, 참고 영상 이용권·초상/음악 등 확인 필요 사항을 기록한다. GPT가 해당 법적 판단을 제시할 때는 현재 공식 근거와 적용 사실을 확인하고 미확인 사항을 구분한다. 자동으로 모든 국가의 적법성 검토가 완료되는 기능은 아니다.

- 공통 사실 원문과 국가별 쟁점(KR/US/JP)을 분리한다. 국가별로 달라야 한다는 근거 없이 운동 방법을 서로 다르게 작성하지 않는다.
- 기록: 해당 문구·장면 / 쟁점 / 국가 / 공식 근거·확인일 / 사실 확인 필요 / 권장안 / 담당 검토 / 사용자 결정 / 반영 상태.
- 일본어·일본 조율은 금윤호, 영어·미국 조율은 김민이다. 필요한 전문가 검토와 실제 적용 여부는 별도로 남긴다. 한국 담당이 필요한 쟁점은 임의 배정하지 않는다.
- 참고 영상 재생과 다운로드·재편집·자체 업로드 권한은 구분한다. 확인 전 권리 확보로 표시하거나 편집/업로드하지 않는다.

## 5. 기록과 재개

**2026-11-11 재개·공유 방식 변경:** 금윤호의 기존 세션 전용 JSON은 원본으로 보존하고, 비민감 검수 기록·체크포인트를 `docs/reviews/handoff/exercise/yunho/`에 옮겨 두 컴퓨터가 함께 참조한다. `docs/reviews/handoff/README.md`에 따라 시작·재개 시 원격 수신, 각 영상 판정/메모/종료 후 기록 전용 공유를 수행한다. 별도 공유 지시를 기다리지 않는다. 서버 DB·브라우저 탭/로그인이 자동 연동되는 것은 아니다. 운동/메커니즘 및 김민/금윤호 기록을 섞거나 덮어쓰지 않는다. 저장 후 다시 읽어 현재 위치·의견 보존을 확인하고 원격 수신 상태를 구분한다.

- 직접 촬영/참고/없음/미확인, 실제 확인 근거

- 결과: 유지 / 설명 수정 / 편집 검토 / 재촬영 검토 / 촬영 필요 / 보류
- 완료 목록·남은 항목·다음 재개 위치

원문 영상·인증정보·일시적인 서명 재생 URL은 공개 저장소나 HANDOFF에 넣지 않는다. 기록 파일 위치를 사용자에게 알려 주고, 다른 컴퓨터에 인계할 때는 안전한 요약/내보내기를 별도로 전달한다. 기록 파일이나 실제 영상이 없으면 대화 기억만으로 검수 완료를 만들어내지 않는다.

### 촬영 필요 목록

**직접 촬영 영상이 없는 운동**을 따로 모은다. 참고 영상만 있어도 촬영 필요 대상이다. '참고 영상만 있음'과 '영상 자체가 없음'을 구분하고, 실제 화면에서 확인한 것만 넣는다. 직접 촬영 영상이 있는 운동 전체를 촬영 필요 목록에 넣지 않는다.

촬영 필요 목록은 별도 지시를 기다리지 않고 **현재 담당 분류에서 확인되는 대로 자동 누적**한다. 예전 범위에서 들어온 다른 담당 운동은 원래 기록을 보존하되 이번 담당 집계에서 제외한다.

금윤호의 예전 워밍업 ‘리버스 토 워크’ 시작 정보는 최신 담당 범위가 아니다. 11월10일 공유 준비 시 확인한 최신 시작 항목은 파워 ‘랜드마인 회전 펀치’였으며, 김민은 그 번호나 판정을 이어받지 않는다. 각자 현재 기록을 다시 읽고 미완료 위치에서 재개한다. 문서의 예시로 전체 수량·완료율을 확정하지 않는다.

## 6. 전체 검수 종료 후 받는 결과물

1. 완료/보류/미재생 목록과 진행 범위.
2. 설명·제목·도구 등 수정 요청표(현재 내용 / 사용자 요청 / GPT 관찰 / 권장 조치).
3. 편집표(운동/영상/정확한 시간대/잘림·대기 등 이유/원본 확인 필요 여부).
4. 재촬영 검토표와 **직접 촬영 영상 없는 운동의 촬영 필요 목록**.
5. 김민·금윤호의 중복 검수 의견과 판정 충돌, 사람이 정해야 할 사항.
6. 우선순위와 Claude 발주 범위, 반영 후 재검수 기준. 사용자 의견을 정리한 것과 실제 반영 완료를 구분.
7. 한국·미국·일본별 표현/안전/효능/권리 쟁점과 미확인·담당 검토·사용자 결정 목록. 후보는 사용자 수정 지시와 분리해서 납품.

**최종 적용 승인:** 검수 중 ‘반영’은 요청을 적어두라는 뜻이다. 전체 검수가 끝나면 사용자 요청·GPT 후보·촬영 필요·국가별 쟁점을 모아 **기존 내용 → 제안 변경 → 이유·영향** 표를 먼저 보여준다. 실제 수정할지 사용자에게 확인한 뒤 승인된 항목만 작업한다. 검수 종료 자체나 앞서 남긴 ‘반영’ 기록만으로 일괄 작업을 시작하지 않는다.

같은 방식은 메커니즘 영상에도 적용할 수 있지만 운동/메커니즘 진행 기록은 별도로 둔다. 검수 방식 공유와 실제 해당 세션의 화면 세팅 완료는 구분한다.

과거 일괄 편집 도구는 `docs/shoot/video-trim-and-content-check.md`에 있지만 **이번 순차 검수 시작에 필요하지 않다.** 그 문서의 과거 수치/판정은 현재 검수 결과가 아니며 설치·다운로드·apply 명령을 이 사용법의 일부로 자동 실행하지 않는다. DB·저장소·원본 영상은 공유 운영 자료다.

## 7. 김민이 GPT에 보낼 시작 지시문

> docs/shoot/exercise-video-review-guide.md의 2026-11-10 업데이트와 최신 공통 지침을 읽고 내 운동영상 검수를 보조해줘. 나는 김민이며 워밍업 → 상체 → 하체 → 모빌리티만 검수할게. 별도 암케어 영상은 담당 범위를 따로 확인하고 임의로 추가하지 마. 기존 내 기록이 있으면 보존하고 미완료 위치에서 재개해. 오른쪽에 영상을 한 개씩 실제로 보이게 열고 현재 영상이 끝나면 처음부터 자동 반복되게 해줘. 영상 교체마다 반복 설정과 실제 재생을 확인해. YouTube 임베드는 재생 설정→옵션 더보기→연속 재생을 확인하되 실제로 현재 영상이 반복되는지 확인하고, 종료만으로 다음 운동에 넘어가지 마. 매 운동의 후보를 제시하기 전에 국내외 논문(가능하면 원저·체계적 문헌고찰)과 공식 학회 자료를 검색해 목적·운동역학·동작·중량·세트·횟수·휴식 근거를 확인하고 구체적인 수정안을 제시해. 성인/청소년·훈련 수준, 운동 변형/장비, 급성 출력/장기 향상, 일반 파워/투구 구속 전이를 구분하고 다른 운동 연구로 수치를 확정하지 마. 직접 근거 미확인은 그대로 밝히고 최적값을 지어내지 마. 출처·결론·적용 한계는 검수 기록에 남기되 앱 설명에 논문을 나열할 필요는 없어. 매번 직접 촬영 여부·영상 편집 후보·설명 수정 후보·한국/미국/일본별 표현·안전·효능 주장·이용권 검토 사항을 안내해줘. 없으면 확인한 범위에서 없다고 해. 법적 판단에는 현재 공식 근거와 미확인 사항을 구분하고, 법률 검토 완료라고 단정하지 마. 직접 촬영 영상이 없는 운동은 참고 영상만 있음/영상 없음으로 나눠 촬영 필요 목록에 자동 기록해. GPT 후보와 내 명시적 수정 지시를 구분해 저장하고, 내가 지시하지 않은 후보는 수정하지 마. 오케이/다음 전에는 넘기지 말고 의견만 말하면 현재 영상을 유지해. 다음 진행은 편집·배포 승인이 아니야. 내 별도 기록을 저장소 밖에 저장하고 다시 읽어 보존을 확인해줘. 금윤호나 메커니즘 기록과 섞지 마. 검수 중 내가 반영이라고 해도 요청 기록만 해. 전체 검수 후 설명 수정·편집·재촬영·촬영 필요·보류·국가별 쟁점을 정리하고, 기존→제안→이유·영향 변경안을 먼저 보여준 뒤 실제 수정할지 나에게 다시 물어봐. 그 승인 전에는 일괄 작업도 시작하지 말고 승인된 항목만 발주해. 지금은 영상/설명/DB/업로드/배포를 변경하지 마. 먼저 내 범위와 재개 위치를 확인하자.


## 공통 플레이어로 검수 영상 열기 — VP01 운영 연결

이 절은 **플레이어를 여는 경로만** 정한다. 콘텐츠 수정·기록·재검수 순서·다음 이동은 해당 파트의 최신 사용자 지시를 따른다. 진행 중인 수정이나 순서를 이 안내로 되돌리지 않는다.

- 운동: `https://dugout-baseball.com/library/training?review=<운동 ID>`
- 메커니즘: `https://dugout-baseball.com/library/mechanics?review=<드릴 ID>`
- 로컬 확인은 위 주소의 도메인을 `http://localhost:3000`으로 바꾼다. 운영 사이트에서 기존 검수 탭을 쓰고 있었다면 배포 후 같은 항목의 주소를 새로 열어 이전 화면 코드를 갱신한다. 현재 번호나 판정을 바꾸지 않는다.
- 메커니즘 DB ID를 모르면 등록된 자체 영상 파일의 확장자를 뺀 ID를 쓸 수 있다. 현재 인계에 있는 예는 `https://dugout-baseball.com/library/mechanics?review=95d8dd7e-6969-4d30-a207-afc89322912f`다. 서버가 권한에 맞춰 불러온 목록 안에서만 찾고, 같은 파일을 쓰는 항목이 여럿이면 자동으로 하나를 고르지 않는다.
- 기존 로그인·베타 권한을 그대로 적용한다. 직접 로그인한 뒤 주소를 다시 열고, **현재 제목·설명·영상 종류를 대조한 다음 그 영상의 재생 버튼을 누른다.** 검수 URL에는 로그인 정보나 서명된 재생 URL을 붙이지 않는다.
- 검수용 주소의 상세는 서버에서 읽을 때 해당 항목·설명을 캐시 대신 직접 다시 조회한다. 운영에서 수정한 뒤에는 이 주소를 새로고침해 최신 내용을 확인한다. 일반 목록과 앱의 캐시 방식은 그대로이며, 검수용 최신 설명을 받은 뒤 예전 설명 조회로 덮어쓰지 않는다. 현재 권한과 숨김 상태를 다시 확인하므로 숨겨지거나 지워진 항목은 자동 대체하지 않는다.
- `?review=`는 선택한 상세 하나를 여는 기능이다. 다음/완료/승인/기록 저장 기능이 아니며 검수 기록을 읽거나 바꾸지 않는다. 일반 목록에서 직접 항목을 열어도 같은 `LibraryVideo`를 쓴다. 항목이 없거나 모호하면 그 상태를 알리고 사용자 지시 없이 다른 영상으로 넘어가지 않는다.
- 직접 촬영은 공통 자체 영상 플레이어, 참고 영상은 공식 YouTube 재생기를 사용한다. 웹의 기존 참고 영상 우선순위(둘 다 등록된 경우)를 유지하며 참고만 있는 항목을 다른 자체 영상으로 대체하지 않는다. 삽입이 금지된 영상은 안내/공식 링크로 남기고 공통 플레이어 적용 완료로 보고하지 않는다.
- 시간 이동·반복·배속이 실제로 동작하는지 확인한다. 반복 종료는 다음 이동 승인이 아니다. 원본 파일 직접 열기·운영 사이트의 예전 재생기·합성 예시 화면만 보고 새 로컬 연결을 확인했다고 하지 않는다.
- 2026-11-13 사용자가 웹 운영 배포를 승인했다. 이 변경을 포함한 운영 배포가 완료된 뒤 위 운영 주소를 사용한다. 소스 푸시만으로 완료라 하지 않고 실제 검수 화면의 공통 조작부와 재생을 확인한다. native 앱의 기존 R3 플레이어와 웹 배포 상태를 구분한다. PC·맥의 브라우저 검수용 경로이며 앱 내부의 기존 native 전환 계약은 유지한다.
