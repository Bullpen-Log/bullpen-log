2026-11-17 사용자 요청. 운동영상 검수에서 배포된 EX-LOAD01/R1을 실제로 활용하기 위한 추가 점검 기준이다. 기존 담당 분류·현재 운동 ID·영상 판·사람 판정·이동 승인·수정 방향은 보존한다. 이 문서 전달만으로 완료 영상을 다시 열거나 콘텐츠/DB를 일괄 변경하지 않는다. 최신 영상별 사용자 지시와 `video-review-current-workflow.md`를 함께 따른다.

## 각 운동에서 추가로 볼 것

1. **시범 장비와 등록 장비의 일치**: 실제 도구와 등록된 장비를 대조한다. 무게를 드는 도구인지 몸을 받치는 장비인지 구분한다. 박스·벤치·철봉 등을 쓴다는 이유만으로 중량 운동으로 분류하지 않는다. 스텝박스와 일반 박스의 기존 구분·해당 운동에 허용된 대체 기준도 유지한다. 제목만으로 동작을 추측하지 않는다.
2. **기록 방식과 무게의 뜻**: 맨몸은 횟수/시간, 자유 중량은 실제 중량, 머신/케이블은 그 기구의 표시 설정, 메디신볼 등은 도구 무게라는 차이를 설명과 기록 입력에 반영한다. 덤벨 한 개/양손 각각/바벨 전체/추가 중량을 혼동하지 않는다. 실제 계약이 제공하는 기준을 확인하며 임의로 합산하거나 계산식을 만들지 않는다.
3. **밴드**: 저항(동작을 어렵게 함)/보조(도와줌)/모름을 구분한다. 시범이 어느 용도인지 근거를 제시하고, 불명확하면 모름/확인 필요로 둔다. 제품 계열·단계·여러 밴드 사용을 확인한다. 색만으로 제품이나 저항을 단정하지 않는다. 카탈로그 단계는 제품 식별자이며 수행한 kg이 아니다. 서로 다른 제품의 색/단계를 동일 강도로 비교하거나 kg으로 변환하지 않는다.
4. **대체/복합/서로 다른 무게**: 밴드 또는 중량 중 하나를 고르는 운동인지 동시에 쓰는 운동인지 확인한다. 양손 무게가 다르면 구성 요소를 보존한다. 기구/설정이 다르면 기록 비교 맥락도 달라진다. 영상과 설명으로 불명확하면 검토 필요로 남기고 장비 태그를 임의로 늘리거나 삭제하지 않는다.
5. **목표와 실제 기록**: 처방/목표와 완료한 세트를 구분한다. 목표를 수정하는 것과 과거 실적을 수정하는 것을 혼동하지 않는다. 설명의 권장 부하와 화면의 목표/실적 기준이 맞는지 확인한다. 자료에 없는 최적 무게·횟수·휴식을 새 기능에 맞춘다는 이유로 만들어 넣지 않는다.
6. **이력과 계산**: 밴드 역할/제품·기구 설정/양손 구성이 이력에서 유지되는지 확인한다. 기록 가능한 운동이라는 이유만으로 모든 운동에 1RM·볼륨·최고 기록 계산이 허용된다고 보지 않는다. 지원되지 않는 비교를 요구하지 않는다. 기존 기록은 삭제·재작성·일괄 보정하지 않는다.
7. **저장 실패와 계정 경계**: 기존 기록에 문제가 보이면 저장됨/보내는 중/보류를 구분한다. 보류는 자동 재전송 약속이 없고, 미해결 기록이 남으면 운동 종료를 막는다. 복구 화면의 원래 장비 정보·이유를 확인할 수 있으나, 영상 검수 자체로 재전송/수정/폐기나 계정 전환 시험을 실행하지 않는다. 다른 계정의 보류 자료를 열람하거나 공개 기록에 옮기지 않는다.

## 화면에서 활용하는 순서

현재 영상을 유지하고 운영 라이브러리 상세를 새로 열어 제목·시범·설명을 함께 본다. 이미 있는 관리자 수정 화면에서 장비/뜻 설정과 입력 안내를 읽되, 단지 검사하려고 저장하지 않는다. 코드의 잠긴 예외 > 저장된 관리자 뜻 설정 > 일반 코드 예외 > 장비 기본값 순서가 있으므로, 화면에서 수정이 막혔거나 모르는 판으로 판정되면 우회하지 말고 담당에게 ID와 이유를 전달한다. 설정은 장비 자체 선택을 대신하는 일반 기록 모드 스위치가 아니다.

설명/제목 수정은 해당 영상에 대한 기존 사용자 방향과 승인 범위 안에서만 진행하고 저장 뒤 다시 읽는다. **이번 기준 인계는 장비 메타데이터·loadSemantics·허용 목록·프로그램·코드·과거 기록을 자동 변경하라는 허가가 아니다.** 그런 불일치는 현재 영상의 후보로 묶어 사용자에게 설명한 후 해당 범위의 명시적 지시에 따른다. 기존 검수가 허용하지 않는 실서비스 세트/목표 생성·저장·실패 주입 시험은 하지 않는다. 실제 기록 왕복이 필요하면 별도의 승인된 테스트 계정/범위를 확정한다.

## 영상별 보고 형식

기존 시범·학술 근거·설명 점검에 다음 짧은 줄을 더한다.

- 실제 장비 / 등록 장비 / 일치 여부와 관찰 구간
- 기록 기준: 횟수·시간·무게의 뜻, 밴드 역할·제품, 대체/복합·양손 차이 등 해당 항목
- 화면 확인: 읽어 확인 / 저장 후 재확인 / 미확인으로 구분
- 불일치와 제안: 무엇을 왜 바꿔야 하는지, 기존 사용자 지시로 수정 가능한지/추가 판단이 필요한지

문제없는 항목까지 긴 양식으로 반복하지 않는다. 이미 완료한 항목의 판정은 유지하고, 새 기준으로 미확인인 부분만 별도로 표시한다. 새 기준에서 문제를 실제 발견한 완료 항목은 재검토 후보에 넣되 완료 취소·자동 재검수·다음 이동을 하지 않는다. 비민감 검수 기록만 기존 동기화 절차에 따라 공유하며 기록자·운동/메커니즘을 섞지 않는다. 다른 컴퓨터의 수신/실제 적용은 확인 전 주장하지 않는다.
