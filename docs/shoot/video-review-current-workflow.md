# 운동·메커니즘 영상 검수 — 현재 공통 세팅

2026-11-13 사용자 지시. 운동영상 세션의 최신 지시를 메커니즘 검수와 김민의 검수에 같은 방식으로 적용한다. 이전 안내의 ‘의견만 기록하고 전체 종료 후 수정’과 ‘매 영상 종료·재반복까지 기다리기’보다 이 문서가 우선한다. 이번 인계 자체로 영상·설명·DB를 일괄 수정하지 않는다.

## 진행 순서

1. `docs/reviews/handoff/README.md`에 따라 자기 기록을 수신하고 현재 항목·미완료 요청을 읽는다. 운동/메커니즘, 김민/금윤호 기록을 분리하고 현재 순서를 초기화하지 않는다.
2. 화면에 보이는 브라우저에서 현재 영상 하나와 제목·설명을 함께 연다. 운동은 `https://dugout-baseball.com/library/training?review=<실제 운동 ID>`, 메커니즘은 `https://dugout-baseball.com/library/mechanics?review=<실제 드릴 ID>`다. DB 항목 ID와 영상 파일 ID를 혼동하거나 추측하지 않는다. 모호하면 기존 목록에서 직접 선택한다.
3. 공통 플레이어로 재생한다. **반복 켜짐 상태만 확인하고 끝나서 다시 시작할 때까지 기다리지 않는다.** 내용 대조에 필요한 장면은 확인하되 반복 시험을 매번 하지 않는다. 재생바·정지·배속·확대를 사용하며 오류면 현재 항목을 유지한다. YouTube는 공식 화면과 지원 기능을 보존한다.
4. 시범·원본 제목·설명을 운동역학 및 국내외 원저·체계적 문헌고찰·공식 학회 자료와 대조한다. 직접 근거와 유사 운동의 간접 근거, 대상·도구·변형·부하·급성/장기 효과를 구분한다. 연구가 없는 최적 중량·횟수·휴식이나 구속 향상 보장을 만들지 않는다.
5. 현재 사용자가 정한 수정 방향과 이 공통 방식의 범위 안에서 **제목·소개·수행 방법·훈련 목적·필요한 처방/안전 문구를 구체화해 먼저 수정·저장**한다. 무엇을 왜 고쳤는지와 근거·한계를 짧게 보고하고 그 영상에서 사용자 확인을 받는다. 저장 성공뿐 아니라 다시 읽어 표시 결과를 확인한다. 불명확한 동작이나 중요한 정책 결정은 추측해 저장하지 않고 질문한다.
6. 사용자 확인 후 ‘다음/오케이’ 등 명시적인 이동 지시가 있을 때만 다음 영상을 연다. 반복 종료·시간 경과·설정 인계는 이동 승인이 아니다. ‘수정하고 다음’처럼 이미 이동을 지시했으면 같은 승인을 반복 요청하지 않는다.
7. ‘기록하지 말고 바로 수정’은 수정 메모만 쌓고 적용을 미루지 말라는 뜻이다. 컴퓨터 간 재개에 필요한 최소 기록은 계속 남긴다: 실제 ID/영상 판, 수정 전후·이유, 저장/재확인 결과, 사용자 확인 대기/완료, 다음 항목, 미해결 사항. 저장 후 읽기 검증하고 승인된 비민감 기록 공유 절차를 따른다.

## 설명 구성과 메커니즘 추가 점검

- **어떤 운동/드릴인가:** 실제 동작을 간단히 설명한다. 원본 영어 제목 해설이나 불필요한 비교로 채우지 않는다.
- **이렇게 하세요:** 시작 자세 → 동작 순서 → 복귀, 장비·부하 선택과 중단 기준을 구체적으로 쓴다.
- **투수에게 왜 필요한가:** 훈련 목적과 관찰할 연결을 설명한다. 실제 투구 동작과 보조 운동을 동일시하거나 효과를 보장하지 않는다.
- 메커니즘은 해당 투구 단계·관찰점·흔한 실수·드릴 목적, 좌우 투수·촬영각도·개인차, 공 던지는 횟수와 일반 반복의 차이를 추가로 대조한다. 3D 엔진·AI 처방 알고리즘은 수정하지 않는다.
- 직접 촬영/참고만 있음/없음을 구분한다. 편집·재촬영이 필요하면 시간대와 이유를 제시한다. **미디어 교체·삭제·다운로드·재업로드·일괄 편집, 새 권리 이용은 별도 구체 지시 없이 실행하지 않는다.**
- 한국·미국·일본의 표현·안전·권리 쟁점을 사실·근거·미확인 사항별로 구분한다. 이 절차만으로 법률 검토 완료를 선언하지 않는다.

## 담당과 저장 경계

김민의 운동 분류는 워밍업·상체·하체·모빌리티, 금윤호는 파워·코어·운동 분류 암케어·회복보강이다. 별도 암케어 담당 경계는 기존 합의를 따른다. 메커니즘 검수 세팅 공유는 담당 재배분이 아니다.

김민은 자기 계정과 자기 진행을 사용하고 금윤호의 완료/판정을 복제하지 않는다. 현재 기록 동기화 도구의 허용 경로는 `yunho`뿐이다. 김민 기록은 `exercise/min/` 또는 해당 별도 검수자 경로로 분리하되, 도구가 그 경로를 지원한다고 가정하거나 yunho로 위장해 게시하지 않는다. 지원되지 않는 기록 공유는 안전한 문서 인계로 처리하고 경로 확장은 별도 구현으로 한다. 로그인 세션·비밀번호·서명 URL·영상 원본은 공유 문서에 넣지 않는다.

## 김민·메커니즘 담당 세션에 전달할 시작 지시문

> 현재 공통 지침과 docs/shoot/video-review-current-workflow.md, docs/reviews/handoff/README.md, 내 담당 인계를 읽고 기존 검수를 이어가줘. 현재 영상·판정·순서를 보존하고 내가 맡은 분류만 검수해. 운영 라이브러리의 공통 플레이어를 화면에 보이게 열고 반복 켜짐만 확인해. 반복되는 순간을 기다리지 마. 각 영상의 제목·시범·설명을 운동역학과 논문/공식 학회 근거로 확인하고, 내가 정한 방향 안의 제목·설명·필요한 처방을 먼저 구체화해 수정·저장한 다음 다시 읽어 결과를 보여줘. 수정한 점·이유·근거의 적용 한계와 내가 확인할 장면을 알려줘. 불명확한 사실은 질문하고 미디어 자체를 임의로 편집·교체하지 마. 내가 다음을 승인할 때만 이동해. 실제 수정과 사용자 확인 상태는 분리해 최소 재개 기록을 저장·공유하고 다른 검수자 기록과 섞지 마. 지금은 기존 현재 항목을 열어 세팅만 맞추고, 인계 때문에 내용을 일괄 수정하거나 다음으로 넘기지 마.
