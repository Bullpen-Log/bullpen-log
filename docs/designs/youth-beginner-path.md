# 성장기 · 입문 투수의 근력 길 — 설계 메모(2026-10-09, 트레이닝 검토 3-⑦)

**상태: 만듦(2026-10-09).** 정한 것: 만 13세부터 · 보호자 확인 없음 · 한 번에 7개(약 35분) · 성인 입문은 4주를 마치면 성인 프로그램이 열린다.

## 왜

- 근력 · 파워 프로그램 7개는 **만 18세 이상 · 입문이 아닌** 사람만 시작할 수 있다(`lib/program/program.ts` checkEligibility).
  설계 D10 의 결정이다 — 청소년 웨이트는 '전문가 감독 아래' 안전하다는 근거(Lloyd 2014)라, 앱이 혼자 무게를 올려 주는 프로그램은
  그 조건이 아니다. **이 결정은 그대로 둔다.**
- 그런데 이 앱을 쓰는 투수의 많은 수가 고교생이다. 그 사람들에게 지금 트레이닝이 주는 것은 '자동 맞춤 · 직접 고르기'(매일 계획)뿐이고,
  프로그램 칸에는 "만 18세부터 해요"만 뜬다. 자동 맞춤은 입문이면 운동마다 짧게(`theme.ts` 의 level ≤ 1) · 초급 운동만(`personalize.ts`
  TRAINING_LEVELS) 주지만, **몇 주에 걸쳐 쌓이는 길**이 없다 — 날마다 새로 뽑는다.

## 제안 — '기본기 4주'(성장기 · 입문 공용)

무게를 올려 주지 않는 길. D10 과 부딪히지 않는다.

| 항목 | 내용 |
|---|---|
| 대상 | 만 13~17세 **또는** 경력 '입문'(성인 포함). 만 12세 이하는 그대로 막는다(안내 문구만). |
| 틀 | 4주 · 주 3번 · 한 번 25~35분. 기존 프로그램 틀(`ProgramDef` · 일차 · 칸)을 그대로 쓴다. |
| 칸 | 스쿼트 계열(맨몸 → 고블릿) · 힌지(힙 힌지 → 덤벨 RDL) · 밀기(푸시업 변형) · 당기기(밴드 · 인버티드 로우) · 한 다리 · 몸통 버티기 · 메디신볼 던지기. |
| 진행 | **횟수 · 세트로만** 올린다(무게 추천 없음, mode `none`). 2주차 세트 +1, 3주차 횟수 +2, 4주차 가볍게. 덤벨 · 밴드 무게는 '같은 자세가 유지되는 가장 가벼운 것' 한 줄. |
| 무게 추천 | 없다. `next-weight.ts` · `free-weight.ts` 를 부르지 않는다('몇 개 더?'도 묻지 않는다). |
| 안전 | 매일 계획과 같은 몸 상태 규칙(통증 멈춤 · 세게 던진 다음 날 가볍게 · 오늘 등판 회복)을 **건다**(성인 프로그램은 §4 의 완화 규칙). |
| 끝 | 4주를 마치면 '자세가 익숙해졌으면 코치 · 트레이너와 함께 무게를 시작하세요' 한 줄. 만 18세가 되고 경력이 초급이 되면 성인 프로그램이 열린다. |
| 근거 | Lloyd 2014(청소년 근력 운동은 자세 · 기술이 먼저), Faigenbaum 2009(맨몸 · 가벼운 저항으로 시작), 설계 D10 의 '자세 먼저인 따로 된 길'. |

## 정할 것(사용자)

1. **대상 나이의 아래 끝** — 만 13세부터? 중학생을 넣을지.
2. **보호자 · 코치 한 줄** — 시작 화면에 "코치나 보호자가 알고 있나요?" 확인 칸을 둘지(둔다면 체크 하나, 저장은 안 한다).
3. **드릴 수** — 한 번에 5개(25분)인지 7개(35분)인지.
4. **성인 입문도 같은 길인지** — 성인 입문은 4주 뒤 바로 성인 프로그램으로 넘겨도 되는지(지금은 경력을 '초급'으로 바꿔야 열린다).

## 만든 것(2026-10-09)

- `lib/program/program.ts` BASICS(`basics-4w`, audience 'basics', required 없음, 모두 mode none) · BASICS_RULES(바벨 · 원판 · 케이블 없이, 매우 높음 · 상급 빼고) ·
  profileBlock · seasonBlock(고르기 화면과 시작 자격이 같은 글) · variantLabel(첫 칸 '던지기 · 점프').
- 한 번에 일곱: 던지기 · 점프 → 스쿼트 → 밀기 → 힌지 → 당기기 → 한 다리 → 몸통 버티기. 1주 2×8 · 2주 3×8 · 3주 3×10 · 4주 2×8(가볍게). 가장 긴 날 약 36분.
- 성인 입문은 기본기를 마치면(`load.ts hasFinishedBasics`) 성인 프로그램이 열린다. 만 17세 이하는 마쳐도 성인은 막힌다.
- **맡겨서 정한 것**: 시즌 중에는 기본기도 시작하지 않는다(경기 앞뒤 쉬는 날이 잦다). 맨몸만이면 당기기 칸이 빈다(라이브러리에 맨몸 당기기가 없다 — 장비 칸에 안내).
- 고르기 화면: 기본기 카드가 목표 칸과 상관없이 맨 위, 성인이 막힌 사람에게 '추천'. 입구 한 줄도 '기본기 4주부터 시작해요'.
- **트레이닝 화면에 카드로 선다**(시트 안에만 두면 입구 줄을 눌러야 보였다 — 사용자 '기본기 카드 안 보여'). 성인이 막힌 사람은 입구 줄 위,
  아니면 아래. 만 12세 이하는 숨김. 진행 중인 프로그램이 있으면 입구 전체가 없다(한 번에 하나).
- 검토(2026-10-09, 3관점 + 반박 확인)에서 고친 것: 저장된 장비가 모자라면 소개 쪽에서 바로 막음(equipmentBlock) · 성인 입문 열림은
  기본기를 절반(6일) 넘게 실제로 한 판만 센다(basicsDoneEnough — 열두 날을 다 건너뛰어도 done 이 되기 때문).
- 시험: `npm run program:test` 1-1) · 2) · 3) 의 기본기 줄.

## 만들 때(제안 때 적은 것)

- `lib/program/program.ts` 에 `ProgramDef` 하나(`goal: 'basics'`), `checkEligibility` 에 'youthOrNovice' 갈래 — 성인 조건을 바꾸지 않고 **옆에** 둔다.
- 운동 고르기(`variantCandidates`)는 맨몸 · 밴드 · 덤벨 변형만 허용하는 선택 칸이 필요하다(지금은 바벨이 1순위).
- 셀프테스트 `scripts/program-selftest.mts` 에 '만 15세는 기본기만 · 성인 초급은 기본기도 되고 성인도 됨' 줄.
- 크기 M(이틀). 설계 문서 `pitcher-strength-power-programs.md` §12 '뒤로'의 성장기 항목을 이 문서로 잇는다.
