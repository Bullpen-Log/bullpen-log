## 2. 바뀌는 틀

평소 하단바(다섯 칸 고정):

```
┌────┬────┬────┬──────┬────┐
│ 홈 │투구│타격│커뮤니티│더보기│
└────┴────┴────┴──────┴────┘
```

투구를 누르면 하단바가 투구 바로 바뀐다(‹ 는 평소 하단바로):

```
┌───┬────┬──────┬────┬──────┐
│ ‹ │기록│트레이닝│암케어│메커니즘│
└───┴────┴──────┴────┴──────┘
```

타격을 누르면:

```
┌───┬────┬──────┬────────┐
│ ‹ │기록│트레이닝│타격 드릴│
└───┴────┴──────┴────────┘
```

| 칸 | 안에 든 것 |
|---|---|
| 홈 | 체크인 · 오늘 링(포지션에 맞는 것만) · 캘린더(투구 · 타격 같이) · 요약 칸 |
| 투구 › 기록 | 지금 투구 탭 그대로(캘린더 · 목록 · 구속 측정 · 3D 동작 분석 · 분석) |
| 투구 › 트레이닝 | 오늘 운동(공통 엔진) · 근력 · 파워 프로그램 |
| 투구 › 암케어 · 메커니즘 | 지금 트레이닝 홈의 두 앱 그대로 |
| 타격 › 기록 | 새 타격 일지 + 캘린더 · 목록 |
| 타격 › 트레이닝 | 오늘 운동(같은 엔진 · 같은 일정) · 프로그램 |
| 타격 › 타격 드릴 | 새 드릴 분류(영상은 촬영 뒤) |
| 커뮤니티 | 그대로 |
| 더보기 | 영양 · 운동 영상 · 투구 드릴 · 고객센터 · 설정 등 |

지금 하단바의 '트레이닝' 칸은 없어진다(트레이닝 홈 `?view=home` 은 종목 하단바로 대신).

## 3. 트레이닝 연동 규칙(D3)

- **일정은 사람마다 하루 하나**(지금도 `DailyTrainingSetup` 은 사람 · 날짜에 하나). 투구 › 트레이닝과 타격 › 트레이닝은 같은 일정을 보여 준다.
- **운동 판도 하루 하나**: 한쪽에서 시작하면 다른 쪽은 '진행 중인 운동 이어 하기', 마치면 둘 다 '오늘 운동 끝'. 두 번째 판을 여는 길은 막는다.
- 엔진은 하나, 포지션이 갈래를 정한다:
  - 투수: 지금 그대로(투구 부하 · 등판 보호 · 팔 예산).
  - 타자: 투구 부하 규칙은 끄고 경기 일정 · 컨디션 · 운동 부하만. 회전 파워 쪽을 조금 앞으로.
  - 투타 겸업: 투수 규칙을 그대로 두고(팔이 가장 다치기 쉬워서) 타격 기록은 1판에선 부하에 안 넣는다.
- 암케어 · 메커니즘 · 타격 드릴은 '오늘 운동'과 따로 된 활동이다(암케어는 트레이닝과 독립 — 2026-10 김민 결정). 두 번 막기는 '오늘 운동'에만 건다.
