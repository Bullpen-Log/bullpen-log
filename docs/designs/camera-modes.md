# 카메라 한 화면 · 두 모드(구속 측정 · ABS) — 설계 1판

2026-10-19 · 금윤호(Claude, 윤호 맥북). 사용자: "홈에서 오른쪽으로 쓸면 바로 카메라가 나오게. 팝업으로 ABS 를 할 거냐 구속 측정을 할 거냐 물어서
들어가게. 두 기능은 같은 카메라 · 같은 인터페이스라, 아이폰 카메라에서 동영상 ↔ 슬로모션 바꾸듯 **한 카메라 앱 안에서 기능만 다르게 도는 느낌**이 중요."

## 0. 한 줄 결론

새 앱(`native/`)의 구속 측정 화면(`src/app/velocity.tsx`)을 **'카메라' 화면**으로 바꾸고, 그 안에 모드 둘(구속 측정 · ABS 판정)을 둔다.
홈 쓸기는 지금처럼 그 화면을 열되, 열리자마자 **카메라 미리보기 위에 모드 고르기 시트**가 뜨고, 고르면 그 모드의 설정 → 셔터로 이어진다.
셔터 위에는 아이폰 카메라의 '동영상 · 슬로모션' 띠처럼 **모드 띠**가 있어 언제든(측정 중만 빼고) 옆으로 밀어 바꾼다.
카메라 · 위 줄 · 셔터 · 수평계 · 존 · 훑기 · 엔진 · 세션 저장은 두 모드가 **같은 부품**을 쓰고, 다른 것은 네 가지뿐이다(2절 표).

## 2. 설계

### 2-1. 들어가기 — 쓸면 카메라, 그 위에 모드 고르기

1. 홈에서 오른쪽으로 쓸면 지금처럼 `/velocity`(이름은 `/camera` 로 바꿔도 되지만 딥링크 · 웹 주소와 맞추려 그대로 둔다)가 옅어지며 들어온다.
   자리표시 글 '구속 측정' → **'카메라'**(레이더 아이콘 → 카메라 아이콘).
2. 열리면 **카메라 미리보기가 바로 보이고**(지금도 켜 둔다 — 설정 카드 대신 미리보기가 주인), 그 위 아래쪽에 **모드 고르기 시트**:
   큰 카드 둘 — `구속 측정`(레이더, "던진 공의 구속을 재요") · `ABS 판정`(존 그림, "볼 · 스트라이크를 판정하고 구속도 같이 재요").
   지난 번 모드가 먼저 골라져 있어 한 번 누르면 들어간다. 닫기(‹)는 홈으로.
3. 고르면 시트가 내려가고 그 모드의 설정 흐름(2-3)으로. 지난 설정이 있으면 지금처럼 '지난 설정으로 바로 시작할까요?'(모드마다 따로 기억).

### 2-2. 모드 띠 — 아이폰 카메라처럼

- 셔터 바로 위에 가로 띠: `구속 측정 · ABS`. 고른 것이 가운데 · 노란 글(아이폰 카메라와 같은 자리 · 느낌), 옆으로 밀거나 눌러 바꾼다.
  바꾸면 셔터 글('측정 시작' ↔ '판정 시작') · 위 줄 제목 · 겹침(존 · 플레이트)만 바뀌고 **카메라는 그대로**(끄지 않는다).
- 설정 단계 중엔 자유롭게, **측정 중(live)엔 잠금** — 바꾸려면 세션 종료. 공통 설정(종류 · 카메라 자리 · 수평 · 존)은 한 번 하면 모드를 바꿔도
  다시 묻지 않고, ABS 전용 단계(플레이트 · 타자)만 더 묻는다.
- 움직임: 띠는 손가락을 따라오고 놓으면 가까운 모드에 붙는다(홈 쓸기 `settle` 과 같은 곡선). 떨림 `selection`.

### 2-3. 모드별로 다른 것 — 넷뿐

| | 구속 측정 | ABS 판정 |
|---|---|---|
| 설정 단계 | 종류 → 카메라 자리 → 수평 → 존 (4) | 같은 4 + **플레이트 보정 · 타자 신장** (5) — 웹 `step 'abs'` 와 같은 내용 |
| 셔터 · 제목 | 측정 시작 · 구속 측정 | 판정 시작 · ABS 판정 |
| 공마다 결과 카드 | 구속 큰 숫자 · 구종 칩 · 믿음 | **스트라이크 / 볼** 크게 + 존 가장자리까지 거리 + 9칸 + 통과점, 구속은 작게 |
| 세션 요약 · 저장 | 최고 · 평균 · 공 목록 | 스트라이크 % · 3×3 · 공 목록(판정 붙음). 저장은 같은 `saveVelocitySession`, 공마다 `analysis.abs`(웹과 같은 칸) |

같은 것: 카메라(2배 · 손떨림 보정 · 60fps) · 위 줄(닫기 · 초점 · 설정) · 수평계 · 릴리스 표적 · 존 겹침 · 알아채기 + 조용할 때 훑기(`capture.ts`) ·
숨은 웹뷰 엔진 · 시도 기록 · 세션 녹화(관리자) · 저장 창. ABS 는 결과가 올 때 `lib/abs judge()` 한 번 더 — 그게 전부다.

### 2-4. 코드 구조(앱)

```
native/src/app/velocity.tsx            카메라 화면(틀) — 모드 상태 · 공통 단계 · 셔터 · 모드 띠 · 모드 시트. 877줄을 아래로 덜어 낸다
native/src/velocity/mode.ts            CameraMode = 'speed' | 'abs' · 이름 · 셔터 글 · 설정 단계 목록 · 마지막 모드 기억(AsyncStorage)
native/src/velocity/mode-sheet.tsx     모드 고르기 시트(카드 둘)
native/src/velocity/mode-strip.tsx     셔터 위 모드 띠(아이폰 카메라 꼴)
native/src/velocity/abs/use-abs.ts     웹 components/abs/use-abs-session.ts 를 앱으로 — 입력은 DualCamera.snapshot, 계산은 lib/abs 그대로
```

### 2-5. 웹(2차)

웹 `VelocityScreen` 은 `absMode` 를 **모드 상태**로 바꾸고 같은 모드 시트 · 모드 띠를 단다. 홈 쓸기(`tab-pager.tsx` zoom)는 그대로 `/velocity`.
`/abs` 주소는 ABS 모드로 바로 여는 딥링크로 남긴다(메뉴 · 공유용). 앱이 자리를 잡은 뒤.

## 3. 단계표(Claude 기준) — 앱 약 14시간 · 웹 2차 3시간

| 단계 | 내용 | 시간 |
|---|---|---|
| 1 | 이 문서 · 사용자 결정 넷(4절) | 끝 |
| 2 | 들어가기 + 모드 틀: 쓸기 자리표시 '카메라' · 모드 시트 · 모드 상태 · 모드 띠(전환만) · 제목 · 셔터 글 · 지난 설정을 모드별로 · `velocity.tsx` 덜어 내기 | 3시간 |
| 3 | ABS 설정 단계: 플레이트 보정(`DualCamera.snapshot` → `findPlateFront`, 못 찾으면 손으로 두 점) · 타자 신장 · 존 겹침을 플레이트 기준으로 | 4시간 |
| 4 | ABS 판정: 결과마다 `judge()` → 판정 카드 · 존 위 통과점 · 타자 칩 · `analysis.abs` 저장 | 4시간 |
| 5 | ABS 요약(스트라이크 % · 3×3) · 저장 창 · 결과 화면(그날 화면에서 판정 보기 — 웹 `abs-summary` 와 같은 글) | 2시간 |
| 6 | 검사: tsc · eslint · 시뮬레이터 굽기. **폰 확인은 사용자**(플레이트 찾기 · 판정은 실제 공이 있어야) | 1시간 |
| 7 | 웹 같은 틀(2-5) | 3시간 |

단계마다 커밋 · HANDOFF(김민 영역 `native/src/velocity/*` · `lib/nav.ts` ABS 관리자 잠금). 2~3 은 사용자 폰 없이 되고, 4~5 는 만들 수 있지만 **실제 판정 확인은 현장**.

## 4. 사용자가 정할 것

1. **팝업을 매번 띄울까** — 추천: 매번 띄우되 지난 모드가 먼저 골라져 있어 한 번 누르면 들어감(홈 쓸기 → 탭 한 번). 대안: 지난 모드로 바로 열고 띠로만 바꿈.
2. **ABS 를 누구에게** — 지금 웹은 검문 2(마커 리그) 전까지 관리자만(`lib/nav.ts`). 추천: 앱도 관리자만 — 일반 사용자 시트엔 ABS 카드를 '준비 중'으로 흐리게.
3. **모드 바꾸기 시점** — 추천: 측정 중엔 잠금(세션 종료 뒤), 설정 중엔 자유. 공통 설정은 다시 안 묻는다.
4. **ABS 세션에 구속도 같이** — 지금 웹처럼 같이 기록(같은 엔진이라 공짜). 추천: 유지.

## 5. 검토 — 걸리는 것 · 위험

- **가장 큰 일은 ABS 화면 부품 7개를 RN 으로 다시 그리는 것**(3~5단계). 계산은 `lib/abs` 그대로라 숫자는 웹과 같다. 3D 존(`zone-3d.tsx`, three.js)은 1차에서 뺀다.
- **플레이트 보정은 2배 줌 · 투수 뒤 1m 앞 조건**(웹과 같다). 앱 카메라가 더 좋아 웹보다 잘 찾을 가능성이 높지만, 실제로 본 적 없다 — 3단계 끝에 폰 확인 한 번.
- `velocity.tsx` 877줄에 상태 20여 개 — 모드를 더하면 더 커진다. 2단계에서 설정 단계 카드 · 저장 창을 파일로 덜어 내며 간다(기능 그대로).
- **ABS 숫자는 아직 '참고'**(P0 실험 전). 화면에 '참고' 배지 · 처리방침은 웹과 같은 글. 검문을 지나면 배지만 뗀다.
- 모드 띠가 아이폰 카메라와 비슷해 보이면 좋지만, 셔터 줄에 이미 세션 녹화 칩(관리자) · 세션 종료가 있다 — 띠는 셔터 **위**에 따로 한 줄(겹치지 않게).
- 앱 ABS 가 생기면 메뉴 `/abs` 는 앱 화면으로 넘긴다(`lib/app-env.ts expoLevel` 올림 → **새 앱을 구워야** 옛 판이 웹을 안 연다).
- 웹과 같은 느낌을 지키려면 웹(2-5)도 결국 같이 가야 한다 — 다만 사용자는 앱이 먼저.
