# 아이콘 체계 — 앱을 아이폰 느낌으로(2026-10-14, 금윤호 → 김민)

금윤호: "지금 쓰는 아이콘이 AI 기본 아이콘 같다. 웹은 괜찮은데 앱에서 우리가 원하는 느낌이 아니다. 아이폰 전화 앱의 부재중 목록 ·
공유 시트 같은 느낌으로. 크게 바꾸는 게 아니라 아이콘의 퀄리티를 올리고 싶다."

## 1. 왜 지금은 부탁해도 안 바뀌나

- 앱은 **lucide** 아이콘(가는 윤곽선, 1.9~2.4px)을 **179개 파일에서 96종** 직접 불러 쓴다(`import { … } from 'lucide-react'`).
- 아이폰 사진의 아이콘은 **SF Symbols** 쪽 — 그림이 아니라 '체계'가 다르다. 선 굵기 · 채움 · 둥근 바탕 · 크기 규칙이 lucide 기본값에 묶여 있어,
  아이콘 하나를 "iOS 느낌으로" 바꾸면 옆 아이콘과 어긋나 더 난잡해진다. 그래서 한 곳에서 규칙을 정하기 전에는 느낌이 안 바뀐다.

| | 지금(lucide) | 원하는 쪽(아이폰) |
|---|---|---|
| 선 | 가는 윤곽선 1.9~2.4px | 굵은 선 또는 **채운 면** |
| 바탕 | 아이콘만 덩그러니 | **색 있는 둥근 원** 위에 흰 글리프 |
| 무게 | 가볍고 도식적 | 둥글고 꽉 찬 느낌(Semibold 이상) |
| 크기 | 16~20px 제각각 | 원 44~56px 안에 글리프 50~60% |

## 2. 방향 셋(추천 순)

1. **그리는 규칙을 한 곳에.** `components/nav-icons.tsx`(이름 → 그림)를 앱 전체로 넓힌다. 색 원 + 흰 글리프 + 굵기를 거기서 정하고, 화면 코드는
   lucide 를 직접 부르지 않고 **이름만** 쓴다. 이게 되면 느낌이 한 번에 바뀌고, Claude 에게 "아이콘 통일"을 시켜도 실제로 바뀐다.
2. **둥근 원 + 앱별 한 색은 이미 반쯤 있다.** 김민이 10-13 에 더보기에 넣은 `NAV_TINT`(위 밝음 → 아래 짙음 두 색) · `components/app-icon.tsx` 가 그 방향.
   하단 탭 · 설정 · 알림 · 공유 시트 · 목록 줄의 동작 단추(전화 · 지우기 같은 것)까지 같은 규칙으로 넓힌다.
3. **글리프 자체를 아이폰 체계로.** 아이폰 앱(Capacitor 웹뷰)은 SF Symbols 글꼴을 직접 못 쓰니, 필요한 40~50개만 SF Symbols 앱에서 SVG 로 내보내
   `public/icons/` 에 둔다. **라이선스 — SF Symbols 는 애플 기기 안에서만.** 웹은 lucide 를 두되 `strokeWidth` 2.5 이상 + 채움 변형(`fill="currentColor"`)으로
   무게를 맞추거나, 채움 변형이 있는 묶음(**Phosphor** Fill/Duotone · **Tabler** Filled)으로 바꾼다.

## 3. 규칙(퀄리티에 실제로 효과 있는 넷)

1. 선 굵기 하나: 아이콘 20px 기준 2.5px. 원 안 글리프는 채움.
2. 원 크기 둘만: 목록 줄 44px, 탭 · 큰 단추 56px. 글리프는 원의 55%.
3. 색 둘만: 테마 파랑(기본 — 파란 원에 흰 글리프) · 앱별 한 색(NAV_TINT). 지우기만 빨강.
4. 어두운 테마는 원 색을 한 단계 밝게(NAV_TINT 의 두 색 규칙 그대로).

## 4. 차례 · 시간(Claude 작업 기준)

- 1단계(규칙 한 곳 + 원 · 틴트 넓히기 — 위 2-1 · 2-2): 약 3시간. 이것만으로 사진 느낌의 80%.
- 2단계(아이폰 앱만 SF Symbols SVG 로 글리프 교체 — 2-3): 약 2시간.
- Claude 에게 시킬 때: "아이콘 하나 바꿔"가 아니라 **"아이콘 체계를 한 파일로 모으고, 거기서 원 · 채움 · 굵기를 정해. 화면 코드는 lucide 를
  직접 부르지 말고 그 파일만 써"**.

## 5. 김민에게 묻는 것

- `app-icon.tsx` · `NAV_TINT` 를 앱 전체 규칙의 뿌리로 삼아도 되나(네가 만든 것이라).
- 1단계를 누가 하나 — 금윤호 쪽에서 하면 `components/app-shell.tsx` 하단 탭 · 더보기를 같이 만지게 된다.
