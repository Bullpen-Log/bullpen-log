# 타격 연습 기록과 영상 카드

- 타격 홈은 오늘의 연습, 선구안 훈련, 주간 기록한 날, 타격 도구, 최근 기록 순서다. 선구안 엔진과 화면은 변경하지 않는다.
- 운동 영상 카드의 이전/다음은 실제 라이브러리의 공개 가능한 영상 중 최신 24개를 보여주며, 영상은 선택해 재생할 때만 로드한다. 전체 라이브러리로 가는 길을 남긴다. 모션 줄이기에서는 전환 애니메이션을 끈다.
- 신규 기록은 `HittingSession`에 두며 `swings = null`은 미입력, `0`은 실제 0이다. 클라이언트가 기록 시작 시 만든 UUID를 저장 재시도에 재사용한다. 이전 `HittingLog`와 새 표는 타격 화면에서 날짜·작성 순서로 합쳐 읽는다.
- 이전 `HittingLog`는 기존 숫자·영상·만족도를 보존하고 기존 계약에 따라 수정한다. 이전 기록의 스윙 수는 삭제해 미입력으로 바꿀 수 없다. 새 표는 이전 웹 코드가 읽지 못한다. 앱의 타격 탭은 웹뷰이므로 새 웹 화면을 불러오는 앱은 새 기록을 보지만, 이전 코드로 되돌리거나 이전 서버를 쓰면 새 기록이 보이지 않는다. 배포·롤백 시 이 차이를 확인한다.
- 적용 전에 상대 개발자에게 공유한 뒤 백업하고 마이그레이션을 적용한다. 코드는 새 표를 읽으므로 DB 적용 전 배포하면 타격 화면이 실패한다. 이 브랜치의 작업만으로 운영 DB나 서비스는 변경되지 않는다. 배포 전 최신 main과 다른 세션의 변경을 대조해 합친다.
