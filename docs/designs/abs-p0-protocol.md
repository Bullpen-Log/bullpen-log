# ABS P0 실험 — 2026-10-19 구속 측정 촬영과 함께(폰 두 대 · 30~50구)

무엇을 확인하나: **뒤 카메라 한 대가 공이 플레이트 면을 지나는 순간(깊이)을 얼마나 맞추나.** 합성 시험대(`npm run abs:bench`)는 깊이 단서 σ 가 0.15m
면 높이 p95 3~4cm, 0.3m 면 7~9cm 라고 한다 — 실제 단서 σ 가 얼마인지는 이 촬영만 알려 준다. 결과가 검문 1을 못 지나면 제품을 '좌우 판정 + 높이 넓은
띠'로 다시 잡는다.

## 준비물(사용자 몫)

- 폰 ① **뒤 카메라** = 제품 조건 그대로: 불펜로그 앱 구속 측정(1080p · 60fps · 2배 · 손떨림 보정) 또는 카메라 앱 같은 설정. 삼각대, 높이 1.3~1.5m,
  **투수판 뒤 3~5m, 투수판~플레이트 선에서 1루 쪽(우투 글러브 반대쪽이면 3루 쪽)으로 0.5m 비킴**(합성 가림 연구: 축 위면 팔로스루 몸통이 공을 52% 가림,
  0.5m 비키면 14%, 1.0m 면 7%). 화면 가운데에 플레이트가 오게.
- 폰 ② **옆 자** = 240fps(슬로모) 아이폰, 삼각대, 플레이트 **앞변의 연장선 위**(1루 또는 3루 쪽 4~6m), 렌즈가 앞변 연장선에 정확히 놓이게(앞변 양끝이
  화면에서 한 점으로 겹치면 맞다). 세로 촬영, 플레이트와 공 높이 1.5m 까지 들어오게.
- 홈플레이트(흰색, 규격 43cm) · 포수 · 격자판 또는 줄자 하나(플레이트 옆에 세워 두는 1m 자 — 옆 영상의 cm/px 를 잰다).
- 동기: 촬영 시작 뒤 플레이트 위에서 **박수 한 번**(두 폰에 다 들리고 보이게), 끝날 때 한 번 더.
- 타자 신장 하나를 적어 둔다(없으면 175cm). 타자가 서면 좋고, 없으면 포수만 있어도 된다.

## 촬영 순서(20분)

1. 두 폰 삼각대 설치 → 뒤 폰 화면 가운데 플레이트, 옆 폰 앞변 연장선 확인(양끝 겹침).
2. 두 폰 녹화 시작 → 플레이트 위 박수 1회.
3. **30~50구**. 존 안 · 바깥 · 높은 공 · 낮은 공을 고르게(투수에게 "코스를 섞어서"). 구속 측정 세션으로 재고 있으면 그대로 진행.
4. 끝 박수 1회 → 녹화 종료. 옆 폰은 영상 한 개(또는 조각 몇 개)로 두어도 된다.
5. 두 영상 + 자 길이 · 신장 · 폰 자리(투수판 뒤 m · 옆 비킴 m · 높이 m)를 메모해 넘긴다.

## 받은 뒤 Claude 가 재는 것(`scripts/abs-p0-score.mts`, P0 끝에 만듦)

1. 옆 영상: 박수 장면으로 시각 맞춤 → 공이 앞변 연장선(화면의 한 세로선)을 지나는 장면 번호를 보간 → **진짜 통과 시각** · 자로 **진짜 높이**.
2. 뒤 영상: 구속 엔진 길(공 찾기 → 궤적 맞추기)로 공을 찍고, 깊이 단서(플레이트 폭 · 포수 발 · 투수 디딤발)로 D 를 정해 `findCrossing`.
3. 숫자 셋:
   - ① 통과 장면 차 RMS(뒤 카메라 보간 − 옆 카메라 진짜) **< 0.3장**(60fps 기준)
   - ② 플레이트 앞뒤 두 장면에 공이 둘 다 보이는 비율 **> 90%**
   - ③ 높이 오차 RMS(뒤 카메라 통과점 − 옆 자) — 합성 예측과 견줘 실제 깊이 단서 σ 를 역산
4. 덤: 투수 몸통이 공을 가린 장면 비율(합성 14% 예측 대비).

검문 1 = ① ② 통과 + 합성 보통 조건 통과. ①이 깨지면 `DEFAULT_BANDS.verticalCm` 을 실측 2σ 로 올리고 제품 글을 '높이는 참고'로 바꾼 뒤 P1 로 간다.
