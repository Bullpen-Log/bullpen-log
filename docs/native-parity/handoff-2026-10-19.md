## 2. 앞으로 할 것(차례대로)

1. **시작 화면 크기 확인**: `native/ios` 는 prebuild 가 만들어(git 밖) 김민 맥북의 storyboard 손질은 GitHub 굽기에 안 실린다. 그래서 고정 300pt(B 150pt)로 맞췄다 —
   GitHub `ios-native.yml` 로 구운 앱에서 '아이콘 → 큰 B → 작아짐'이 튀지 않는지, 다크 테마로 두 번째 켤 때 흰 판이 없는지 본다.
2. **앱 구속 측정 실기기 첫 확인**(관리자 계정): 설정 4단계 → 셔터로 측정 → 몇 구 → 세션 종료 → 체감 강도 → 저장. DB 에 세션 · 공 · 클립이 들어왔는지(읽기만), 세션 녹화 조각이 붙었는지.
   막히면 `[velo]` 로그 · 시도 기록(VelocityAttempt). 잰 공이 0개면 저장 단추가 안 뜨는 것(김민 인계 메모의 '고치지 않은 것')도 같이.
3. **앱 측정에 훑기(sweep) · 학습 공 감지 모델 옮기기** — 김민 구속 인계(`docs/velocity/engine-2.7-plan.md` 끝 '인계' 절 ①). 시계는 `DualCamera.now()`(이번에 넣음).
4. **탭 막대 유리**: 김민 참고 = iOS 26 앱 스토어 탭 막대(누른 채 밀면 렌즈가 따라오고 렌즈 속 아이콘이 파랗게 확대, 가장자리 무지개 굴절). 시뮬레이터에선 유리가 잘 안 보이니 **폰에서**.
5. 남은 웹 화면 중 앱으로 옮길지 김민과 정하기(촬영 모드 · 녹화 편집기 등).
6. 정식 출시 전: `expo-updates` · `runtimeVersion`(N3) · 운동/드릴 영상 앱 안에 싣기(네 10-19 메모의 '같이 정하자').

## 3. 알아 둘 것(함정)

- **김민이 원하는 기준**: "웹 앱이랑 똑같이" — 움직임 · 크기 · 때까지. 말로 넘기지 말고 **화면 녹화로 보며** 고친다(김민이 녹화를 보내면 장면을 0.03~0.1초로 뽑아 장면 모음으로 본다 —
  AVFoundation `AVAssetImageGenerator` 로 swift 스크립트 몇 줄, ffmpeg 없음). 내가 틀린 길: 탭 누를 때마다 유리 렌즈 · 렌즈가 아이콘 위에 그려짐 · 시작 B 를 화면 폭 가득.
- **유리(GlassView)**: iOS 26 이상만(`isLiquidGlassAvailable`). 알파로 숨기면 효과가 꺼진다 — 스타일 `'none'` ↔ `'clear'` 로 켜고 끈다. 형제 층 · zIndex 와 상관없이 위에 그려진다.
- **reanimated 첫 장면**: 움직임 스타일이 한 장면 늦게 붙을 수 있다 — 정지 모양(첫 장면에 보여야 할 모습)을 기본 스타일로 둔다(시작 연출에서 이름이 한 장면 비쳤던 까닭).
- **폰에 바로 깔기**(김민 맥북에서 쓰던 것): `xcodebuild build -workspace BullpenLog.xcworkspace -scheme BullpenLog -configuration Release -destination id=<폰 UDID>
  -derivedDataPath <임시> DEVELOPMENT_TEAM=<팀> CODE_SIGN_STYLE=Automatic -allowProvisioningUpdates -allowProvisioningDeviceRegistration` → `xcrun devicectl device install app --device <폰>
  <…>/Release-iphoneos/BullpenLog.app`. 폰이 잠기거나 멀면 'unavailable' · 4016. 임시 굽기 폴더가 쌓여 **디스크가 꽉 차면** 굽기가 깨지고 모듈 캐시(`ModuleCache.noindex`)도 깨진다 — 지우고 다시.
- 시뮬레이터 카메라 없음 — 측정 화면은 '카메라 오류' 창이 뜬다(단계 화면만 보려면 그 분기를 잠시 끄고 보고 되돌린다).
- main 에 올리기는 **30분 간격**(Supabase 풀러 200 연결이 연속 배포로 찼다). 앱만 고친 커밋도 Vercel 빌드는 돈다.
- 앱 서버 동작 모양: 새 rpc 를 부르면 `npm run native-api:test -- --update`.
