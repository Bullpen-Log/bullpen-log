# 트레이닝 — 웹 ↔ 아이폰 앱 같게(2026-10-18, 네이티브2)

김민: "기존 웹 기반 앱과 인터페이스 · 기능이 많이 다르다, 느낌도 다르다." → 웹에 있는 것은 앱에도. 트레이닝 전체(첫 화면 · 오늘 운동 · 운동 진행 ·
운동 끝 · 암케어 · 메커니즘 · 재활 · 프로그램 · 루틴 · 그날 기록 · 워밍업 · 트레이닝 설정)를 웹 코드와 앱 코드를 끝까지 읽고 견줬다(읽기 넷 → 표 넷).

- 줄마다 판정(같음 / 앱에 없음 / 다름(무엇이))과 **결과**(고침 / 남김(까닭)). 메모 칸의 '앱 주석 …'은 코드 주석에서 옮긴 까닭이다.
- 고칠 때 계산은 앱에 새로 짜지 않았다 — 웹과 같은 서버 동작 · lib 를 쓴다. 웹 화면 안에만 있던 셈(이번 주 날 수)은 lib 로 빼 둘이 같이 쓴다.
- '빈도'(높음 · 보통 · 낮음)는 읽은 쪽이 매긴 쓰는 빈도. 표 끝의 '상위 10'은 고치기 전 차례표 그대로 둔다(무엇부터 했는지).

## '앱에 없음 · 다름' 상위 10 (자주 보이는 순)

1. **설정 입구가 위가 아니라 맨 아래 (높음).** 웹은 제목 오른쪽 '설정' 알약, 앱은 맨 아래 '트레이닝 설정 · 장비' 줄입니다 (W-page:144-159 ↔ A-today:265). A-today:167의 빈 오른쪽 칸에 설정 단추를 두고 `/training/settings`를 열면 됩니다. 쓸 것: `training-setup.loadAppTrainingSettings`.
2. **무게의 까닭이 시스템 알림창 (높음).** W-card:320-341 ↔ A-card:76-88. 이미 있는 `Sheet` (native/src/workout/sheets.tsx)로 ReasonBody 모양을 옮기면 됩니다. 서버 동작은 필요 없습니다 (`ProgramCardProps.rows` 값을 그대로 씀).
3. **'선택' 배지 · tag 칩 모양 (높음).** W-card:142-156 ↔ A-card:134-138. 모양만 다르고 서버는 안 건드립니다.
4. **앞으로 할 세션 (보통).** 처방 한 줄이 웹은 눌러야 보이고 앱은 늘 보입니다. 앱 세션 줄에는 펼침 화살표도 없습니다. W-card:450-525 ↔ A-card:254-301. 자료는 같은 `ProgramCardProps.upcoming`입니다.
5. **확인 창 진행 글이 없음 (보통).** '넘기는 중… / 그만두는 중… / 바꾸는 중…'이 앱에 없고, 확인 단추 색도 다릅니다. Alert 대신 확인 시트로 바꾸거나 카드에 진행 표시를 두면 됩니다. 쓸 것: `program.skipProgramDay`, `program.stopProgram`, `program.overrideProgramRest` (지금도 부름).
6. **암케어 화면에 설정 입구가 없음 (보통).** W-page:234-243 ↔ native/src/app/training-armcare.tsx. `/training/settings`로 가는 길만 더하면 됩니다.
7. **장비 저장 단추 (보통).** 저장 중 글이 웹 '저장 중…', 앱 '저장하는 중'으로 다르고, 앱은 바뀐 게 없으면 단추를 잠급니다. 저장 알림도 웹은 토스트, 앱은 흐린 글입니다. A-set:125-131 ↔ W-form:602. 쓸 것: `training-setup.saveAppOwnedEquipment`, `saveAppTrainingLevel`.
8. **앱 설정 화면에만 있는 글과 단추 (보통).** '오늘 만든 일정은 그대로예요. 새 설정으로 받으려면…' 글과 [닫기] 단추입니다 (A-set:133-136). 웹에 넣을지 앱에서 뺄지 정해야 합니다.
9. **장비를 처음 고르는 칸과 장비 경고 (낮음).** 앱은 그 자리 폼 대신 설정 화면으로 보내고, 안내 뒤 문장 '아무것도 없으면 그대로 저장하세요.'와 경고의 '위 ‘트레이닝 설정’에서 고르세요.'가 빠졌습니다 (A-forms:74-79, A-plan:455-457 ↔ W-form:290-304, W-page:851). 그 자리에서 저장하려면 쓸 것: `training-setup.saveAppOwnedEquipment`, `SELECTABLE_EQUIPMENT` (lib/report/equipment.ts).
