상태: 같음 / 앱에 없음 / 다름(무엇이). 빈도: 사용자가 얼마나 자주 쓰나. 조치: 이번에 고침 / 남김(까닭).

## 이번에 고친 것(가지 native3)

- **영양 담기**(`native/src/app/nutrition/add.tsx`): 담아도 창이 안 닫히고 아래에 '○○ 담았어요 · N번 담았어요' + [다 했어요], 줄 옆 + 한 번에 1인분, 담으면 진동,
  빠른 칩 0.5 · 1 · 1.5 · 2 · 3 과 −/+(1 밑 ¼ · 위 ½) — 웹 규칙을 `lib/nutrition/meta.ts` `QUICK_AMOUNTS` · `stepAmount` 로 옮겨 웹 음식 창과 같이 쓴다.
  찾는 칸 '음식 이름이나 초성 (ㄷㄱㅅㅅ)', '‘…’에 맞는 음식이 없어요.'(식약처가 꺼져도), 식약처 출처 한 줄.
- **영양 끼니 칸**(`native/src/nutrition/tab.tsx`): '단백질 18 / 목표 35g' + 가는 막대 + 다 채우면 ✓(초록), 모자라면 '단백질 17g 모자라요 · 달걀 2개 · 우유 1컵(+19g)이면 채워요'
  — 웹과 같은 `lib/nutrition/meal-protein.ts` `mealProtein`. 서버 `app.loadAppNutrition` 응답에 `ageBand` · `avoid` 두 칸을 더했다(옛 앱은 모르는 칸이라 그대로).
- **분석**(`native/src/app/analysis.tsx`): 구속 · 무게를 설정 단위대로(하이라이트 · 개인 최고 · 그래프), 고른 기간(4주 · 12주)을 웹과 같은 열쇠 `bullpen-trends-range` 에 기억,
  '‹ 투구 기록' · '‹ 트레이닝' 돌아가기 이름표.
- **더보기**(`native/src/app/more.tsx`): 하단 탭에 있는 홈 · 투구 · 트레이닝 · 영양을 웹 폴더처럼 뺀다(이름 + 그림이 같은 것), 내 정보 · 설정은 더보기를 닫지 않고 그 위로 연다.
- **영양 끼니 편집**(`native/src/nutrition/tab.tsx`): 끼니 머리 '편집'(또는 음식 줄)을 누르면 줄마다 양 −/+(1 밑 ¼ · 위 ½) · 다른 끼니로 옮기기 · 지우기(되살리기),
  밑에 '모두 지우기 / 모두 되살리기'. '완료'에 고친 줄만 한 번에 저장(웹과 같은 `nutrition.editMealEntries`), '취소'는 그대로. 식단(계획) 줄 양 고치기 · 빼기는 아직.
- **설정**(`native/src/app/settings.tsx`): 테마 고르개에 웹과 같은 뜻의 그림(해 · 달 · 달과 별 · 반쪽 원).
- **내 정보**(`native/src/app/profile.tsx`): 키를 설정의 길이 단위대로(cm · in, 저장은 정수 cm — 웹 profile-form 과 같다).
- **계정**(`native/src/app/account.tsx`): 탈퇴 안내 · 단추를 웹 문구로('되돌릴 수 없어요 …', '탈퇴하고 모든 기록 지우기').

## 남긴 것 — 큰 덩이와 까닭

- **영양 오늘 카드의 할 일 한 줄 · 균형 점수 · 먹은 % 링 · 던지는 날 가이드 · 영양 추세 경고**: 웹은 `loadAdvice`(lib/nutrition/advice-load.ts, 서버 전용)로 짓는다.
  앱에 셈을 새로 짜지 않으려면 그 결과를 내려 주는 서버 동작이 필요하다 — 다음 차례(`app.loadAppNutrition` 에 `advice` 를 싣는 길).
- **영양 어제와 같이 · 자주 먹는 조합 · 바꾸기 · 직접 입력 · 분류 둘러보기 · 날짜 띠 · 작은 달력 · 식욕/끼니 카드**:
  웹 서버 동작(`addMealEntries` · `editMealEntries` · `replaceMealEntry` · `saveNutritionCheckin` …)은 이미 있어 앱 화면만 만들면 된다 — 화면이 커서 다음 차례.
- **분석 '그날 분석'으로 들어오기 · /coach?date= 주소의 날짜**: 홈 그날 카드(다른 세션 영역)와 `native/src/app/index.tsx`(공용) 손이 필요하다.
- **기간 설정(시작 · 끝 달력)**: 앱은 서버가 정한 기간(SERIES_DAYS)만 받는다 — 서버 동작에 기간 인자를 더해야 한다.
- **설정 · 내 정보를 창으로 띄우기**: 앱은 쌓이는 화면이다. 창(모달)으로 띄우려면 `_layout.tsx`(공용).
- **이용약관 · 개인정보 처리방침 앱 안 보기 · 생년월일 달력 · 사진 안내 글**: 덜 자주 씀.
- **라이브러리 탭(운동 영상 · 투구 드릴 · 워밍업 루틴) · 워밍업 화면 · 거르기 시트**: 워밍업은 `NATIVE_ROUTES`(공용 index.tsx)와 새 서버 내보내기가 필요하다.
- **관리자 쪽 전부**: 관리자 몇 명만 쓰는 화면이라 사용자 화면 뒤로. 촬영 체크 되돌리기 · 15초 맞추기가 그중 먼저.
- **움직임(숫자 올라감 · 막대 솟기) · 뼈대 로딩**: 기능을 다 맞춘 뒤.

### 2. 고칠 것 (중요한 순서, 최대 12개)

`app/api/rpc/registry.ts:41,22,36`을 보면 `profile`, `auth`, `onboarding-state` 모듈이 통째로 등록돼 있습니다. 그래서 아래 고칠 것은 모두 **새 서버 액션 없이** 됩니다.

1. **더보기 위로 설정·내 정보 열기, 닫으면 더보기로 돌아오기** (`nM:69-70`): `router.back()`을 빼고 모달 위로 push 하면 Bar의 '‹ 더보기'와 맞습니다. 서버 액션은 필요 없습니다. native-stack에서 모달 위에 push 했을 때 어떻게 뜨는지는 확인해야 합니다. 설정·내 정보를 `presentation: 'modal'`(또는 formSheet)로 바꾸려면 `native/src/app/_layout.tsx`를 고쳐야 하는데, 이 세션은 못 고칩니다.
2. **더보기에서 하단 탭 넷 숨기기** (`nM:76`): 웹처럼 이름+아이콘으로 견주면 됩니다. 쓸 것은 `MOBILE_TABS`(`lib/nav.ts:321`), 또는 `DEFAULT_TABS`(`native/src/shell/tab-bar.tsx:13`)를 import만 하면 됩니다. 셸 파일을 고칠 일은 없습니다.
3. **더보기를 웹 폴더처럼 격자로**: 제목 없는 묶음 합치기, 한 줄 3개 아이콘 타일, 설정 타일은 격자 끝, 내 정보는 맨 아래(`DM:368-532`와 같게). `nM` 한 파일만 고치면 됩니다. 서버 액션은 필요 없습니다. 아이콘 칠은 웹 `NAV_TINT`(components/nav-icons.tsx)의 값을 옮겨 써야 합니다. 테마 색 토큰을 새로 만들어야 하면 `native/src/lib/ui.ts`가 금지 파일입니다.

### 2. 고칠 순서 (중요한 것부터)

앱이 부를 수 있는 서버 모듈은 `app/api/rpc/registry.ts`에 올라 있는 것뿐입니다. 이번 작업과 관련된 `app-library`, `community`, `support`, `board`, `content`, `favorite`, `warmup`, `exercise-history`는 모두 올라 있습니다. 다만 `warmup.ts`와 `content.ts`의 관리자 동작은 웹 폼(FormData) 방식이라 앱에서 그대로 못 부르고, 새로 앱용 입구를 만들어야 합니다. 새 입구를 이미 올라 있는 파일(`app-library.ts` 등) 안에 export로 더하면 registry는 고치지 않아도 됩니다.

1. **라이브러리 탭 3개 넣기** (운동 영상 · 투구 드릴 · 워밍업 루틴, 탭마다 설명 한 줄 — 웹 `tabs.tsx:7-26`)
   - 고칠 곳: `native/src/app/library/training.tsx:97`, `mechanics.tsx:86` 막대 밑. 탭 부품은 `native/src/library/parts.tsx`에 새로 둡니다.
   - 서버: 필요 없음.
   - `Bar`(`native/src/community/parts.tsx:90`)는 그대로 쓰면 되므로 community/parts.tsx는 건드리지 않습니다.
2. **워밍업 루틴 화면 새로 만들기** (보기 전용: 안내 카드 · 루틴 카드 · 번호 매긴 운동 · 처방 · 빈 화면)
   - 새 화면 `native/src/app/library/warmup.tsx`. 앱 주소 목록(`native/src/app/index.tsx:71`)에 `warmup`을 더하고, 웹 `app/(app)/library/warmup/page.tsx` 맨 앞에 다른 화면들처럼 앱으로 넘기는 코드를 넣습니다.
   - 서버 새로 필요: page.tsx:25-83의 읽기를 `lib/library-load.ts`로 옮긴 함수로 만들고, `app/actions/app-library.ts`에 `loadAppWarmupRoutines` 같은 이름으로 더합니다. 웹 page.tsx도 같은 함수를 쓰게 합니다.
   - '하는 날' 이름표 `WHEN`(`warmup-client.tsx:46-51`)은 공용 lib로 빼서 함께 씁니다.
   - 처방은 `formatPrescription`(`lib/exercise-meta`), 미리보기는 `referenceThumbUrl`(`lib/reference-video`)과 `createPlaybackUrls`(`lib/storage`)를 씁니다.
