# 싱커 미국·일본 출시 통합 작업 기준

최종 사용자 합의: 2026-11-06. 다음 주(2026-11-09~15) 출시 목표이며 정확한 출시일은 미정. 심사 승인을 보장하는 일정이 아니다. 체크되지 않은 항목은 완료로 간주하지 않는다.

## 작업 환경과 책임
- 맥 미니가 메인 개발 환경. 이 맥북은 서브 작업 환경이다.
- 금윤호: 일본 시장 책임자. 일본어 번역·현지화·일본 법률 검토·스토어/출시 검수 조율.
- 김민: 미국 시장 책임자. 영어 번역·현지화·미국 법률 검토·스토어/출시 검수 조율.
- 기능 담당과 국가 담당은 별개다. 기능 담당은 원문/동작/데이터 설명을 제공하고, 국가 담당은 모든 출시 기능의 현지 번역·표현·법률 검토를 책임진다.
- 아래는 계획이며 법률 검토 완료나 출시 승인 기록이 아니다. 법 적용은 실제 사업·데이터·결제 흐름에 따라 전문가와 판단한다.

## 기능 담당(사용자 확정)
| 기능 | 담당 |
|---|---|
| AI코치 | 김민 |
| 투구기록 | 금윤호 |
| 3D동작분석 | 김민 |
| 영상비교 | 금윤호 |
| 운동 영상: 워밍업/상체/하체/모빌리티 | 김민 |
| 운동 영상: 파워/코어/암케어/회복보강 | 금윤호 |
| 암케어 영상 | 김민 |
| 메커니즘 영상 | 금윤호 |
| 덕아웃 | 금윤호 |

암케어 담당 중복은 미결: 프로그램 구성·안전 기준과 개별 운동 제작/등록의 소유권을 둘이 확정한다. 임의로 담당을 변경하지 않는다.

## 이번 출시 범위
- 투구기록 → 영상 확인/비교 → 운동·메커니즘 학습의 흐름을 완성한다. AI코치·3D 분석은 김민 담당으로 통합 검수한다.
- 구속측정·ABS는 미완성이므로 이번 출시 제외. 완성 후 별도 출시한다. 메뉴뿐 아니라 직접 주소·API·검색·옛 링크·AI 안내도 공개 정책과 일치시킨다.
- 해외 덕아웃은 커뮤니티 중심의 최소 범위를 권고한다. 국내 장터/레슨/예약까지 해외 공개하는 것은 사용자 확정 사항이 아니다.

## 금윤호 기능별 필수 작업
- [ ] 투구기록: 빠른 입력/선택 입력, 저장·수정·삭제·실패 시 입력 보존·중복 방지, 날짜별 탐색, 영상비교 진입, 현지 날짜/시간대/단위. 직접 입력 구속이 있으면 자동 측정과 구분.
- [ ] 영상비교: 투구 탭 주요 진입, A/B 선택·교체·기준 맞춤, 동시/개별/프레임/속도 조작, 분할·반투명 겹침·전체/채움, 도구 숨김/복원, 주석/메모/저장 복원, 권한 거절/파일 유실/재생 오류 복구.
- [ ] 영상비교 실기기: 작은/표준 iPhone, 스크롤 없는 핵심 조작, 실제 두 영상 합성·동기화·백그라운드 정지·회전·키보드/IME·VoiceOver·큰 글자. 이전 모의 검사 통과를 기기 검증으로 간주하지 않는다.
- [ ] 운동 영상: 파워/코어/암케어/회복보강. 운동명·목적·장비·시작 자세·순서·호흡·세트/횟수/시간/휴식·좌우 기준·실수·중단 안내·쉬운 대안·자막·썸네일을 통일하고 전문가 검수.
- [ ] 메커니즘: 준비/균형·중심 이동·착지·몸통/팔·릴리스/팔로스루. 개념→관찰점→실수→드릴. 좌우 투수·촬영 각도·개인차 구분, 영상비교와 연결.
- [ ] 덕아웃: 국가/언어 노출, 글/댓글/수정/삭제, 신고/차단/운영 대응, 빈 상태, 국내 전용 서비스의 해외 노출 차단. 공개 범위 최종 합의.

## 국가별 번역·현지화(일본 금윤호 / 미국 김민)
- [ ] 화면·버튼·온보딩·빈 상태·로딩·오류·권한·알림·메일·고객센터·웹뷰·약관/동의·스토어 설명/스크린샷까지 번역 목록 작성.
- [ ] 공통 야구/운동/해부 용어집과 번역 키 정리. 김민 담당 기능도 일본어는 금윤호, 금윤호 담당 기능도 영어는 김민이 검수.
- [ ] 영상 제목/설명/자막/주의사항 번역. 이미지 속 한국어와 잘린 글자, 조사/줄바꿈, VoiceOver 라벨도 검수.
- [ ] 날짜/시간대·수치·단위·가격(유료 시) 현지화. 국가/언어/스토어 국가를 혼동하지 않고 언어 선택/대체 언어 정책 확정.
- [ ] 원어민의 야구 문맥 검수와 실제 앱 흐름 검수. 번역 존재만으로 완료 처리하지 않음.

## 법률·정책 검토
공통 준비: 실제 수집 데이터/이용 목적/보관/삭제/수탁사/저장국/AI 전송·학습 이용 여부·공개 범위 도식, 유료 여부·대상 연령·운영자 정보 확정. 면책문만 추가해 끝내지 않는다.
- [ ] 일본(금윤호): APPI 적용·이용 목적 고지·해외 이전/제3자 제공의 해당 여부와 적법 근거·이용자 권리·문의/사고 대응. 한국 서버 및 외부 AI 제공사 흐름 포함.
- [ ] 일본(금윤호): 일본어 이용약관/개인정보처리방침/AI 안내, 미성년 이용 정책, 영상 초상·저작권/음악·콘텐츠 이용권, 운동/건강 효능 표현 검토.
- [ ] 일본(금윤호): 유료 판매/구독을 제공하면 특정상거래법 표시·요금·갱신·해지·환불·최종 확인과 소비자계약 관련 사항의 적용 검토. 무료/결제 없음이면 해당 근거와 추후 재검토 조건 기록.
- [ ] 미국(김민): 실제 적용되는 연방/주 개인정보·소비자 건강정보 규정, FTC 건강 앱 관련 규정과 사고 통지 해당성. HIPAA가 모든 건강 앱에 자동 적용된다고 가정하지 않음.
- [ ] 미국(김민): 대상 연령·COPPA 적용 판단과 필요한 보호자 동의, 약관/개인정보/AI 고지, 효능 광고, 영상 이용권, 유료 시 구독/해지/환불 정책.
- [ ] 공통: AI/3D/운동 안내를 의료 진단·치료·부상 방지 보장으로 오인시키는 표현 검토. 신고/차단·계정 삭제·지원 연락처·스토어 개인정보 신고와 실제 동작 일치.
- [ ] 검토 기록: 쟁점/실제 흐름/적용 판단/수정/검토자/검토일/잔여 위험/공개 가능 여부를 남기고 미해결 중요 쟁점은 출시 판단에 반영.

## 공동 출시 체크
- [ ] 계정 생성·로그인·복구·탈퇴·계정 전환 및 영상 삭제 범위.
- [ ] 일반 계정의 출시 기능 허용표 확정. 베타를 정식으로 변경하는 것만으로 구속/ABS 제외가 보장되지 않으므로 별도 검수.
- [ ] 국가별 첫 기록→영상비교→운동 탐색 통합 테스트, 느린 망/오류/권한 거절/계정별 접근.
- [ ] App Store 국가별 메타데이터·스크린샷·지원/정책 주소·연령 등급·개인정보 신고·심사 접근 안내·배포 국가. 정확한 출시일은 별도 확정.
- [ ] 오류 수집·문의 담당·신고 처리·기능 차단/복구·배포 후 확인 준비.

## 추가 기능 권고(확정 요구와 구분)
우선: 기록→비교 바로가기, 촬영/기준 장면 안내, 짧은 첫 사용 안내. 기존 구현 활용: 운동 즐겨찾기/최근 본 운동·주간 요약. 비교 내보내기/코치 공유는 안정성이 검증될 때만. 새 대규모 기능으로 출시를 지연시키지 않는다.

## 출시 순서
1. 즉시: 출시 기능표·암케어 경계·대상 연령·유료 여부·번역/법률 책임 확정, 법률 검토 착수.
2. D-6~5: 기록/비교 핵심 마무리, 국가 노출·미출시 차단.
3. D-5~4: 콘텐츠/번역·정책 수정과 원어민 검수.
4. D-4~3: 실제 iPhone 통합 검수, 스토어 제출 준비 및 준비된 후보 조기 제출.
5. D-3~1: 오류/심사 대응, 후보 동결, 미해결 법률·권한·데이터 문제 확인.
6. 출시 후: 배포 확인·문의·오류·첫 사용 흐름 관찰. 심사 완료 여부에 따라 공개일 조정.
