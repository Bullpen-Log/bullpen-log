## 3. 추가로 적용한 검수 기준

1. **영상과 등록 정보 대조.** 제목은 시범이 드러나는 쉬운 용어로 쓴다. 영상 표기 제목을 쓰라는 개별 지시가 있으면 반영한다. 시작·끝·반복 연결·어색한 추가 동작·타인 노출·잘림을 보고 전체/일부/미재생 범위를 상대에게 알린다. 직접 촬영·참고만 있음·원본 미확인을 구분한다. 직접 촬영은 대표 장면을 확인하고 참고 제공자의 썸네일은 임의 수정하지 않는다. 지원되는 화면에서 무음·반복 상태를 확인한다. 반복 종료로 검수 위치를 옮기지 않는다.
2. **설명의 네 칸.** 어떤 운동인가 / 이렇게 하세요 / 투수에게 왜 필요한가 / 강도. 수행은 시작→동작→복귀, 장비 고정·공간·안전·통증이나 자세 저하에 따른 중단은 수행 끝에 둔다. 노력·무게·높이·저항·속도 조절은 강도에 둔다. 문장마다 줄바꿈하고 단계 사이를 비운다. 번호·소수점을 보존하고 자동으로 접힌 줄도 번호 또는 ■ 뒤 본문 첫 글자에 정렬한다. 기존 43개 설명의 형식 재저장은 영상 재시청과 별개다.
3. **실제 투구와 수행 방향.** 움직이는 발, 목표 방향, 착지, 릴리스, 실제 시범 횟수와 우투·좌투 기준을 확인한다. 일반 파워는 대체로 양쪽을 수행하고 직접 던지면 개별 동작의 기준을 확인한다. 공을 실제로 던지는 횟수와 일반 반복을 구분한다. 스로잉 태그는 던지는 기술 또는 속도 자체가 목표일 때 붙인다. 드리프트는 목표 쪽 중심 이동, 상하체 분리는 관찰 가능한 회전 순서를 근거로 한다. 큰 공·작은 공·다른 고정 방향처럼 수행이 달라지면 각각의 목적·우선순위·단계를 확인하고, 실제 동작과 목적이 같은 경우 기존 ID와 제외 근거를 남긴다.
4. **운동역학과 근거.** 플라이오메트릭은 실제 동작, 기본/반응 단계와 투구에 쓰이는 능력을 구체적으로 연결한다. 아이소메트릭은 자세·힘의 방향·호흡·운동별 노력과 시간을 확인한다. 메커니즘은 Driveline 관련 공식 자료를 먼저 보고 Tread의 고유 주장에는 Tread 1차 자료를 대조한다. 원저·공식 학회·직접 근거와 유사 동작의 간접 근거, 코칭 사례를 구별한다. 근거가 없는 일괄 30초, 최적 무게·횟수·휴식, 구속 향상을 단정하지 않는다.
5. **장비와 기록 방식.** 실제 장비와 태그, 몸 받침과 추가 중량, 도구당/한 손/바벨 전체/기구 표시 무게를 구분한다. 스텝박스 대체는 해당 동작 기준으로 판단한다. 밴드는 저항/보조/불명, 제품과 단계로 남기며 색을 kg으로 환산하지 않는다. 대체/복합, 양손 무게, 목표와 실적, 1RM·볼륨 계산 적합성, 세트·좌우 횟수·휴식을 확인한다. 기록이나 프로그램의 일괄 변경은 별도다.
6. **사용자 판정과 실제 반영.** 승인된 현재 영상 설명·제목·대표 썸네일을 바로 저장하고 화면을 재조회한다. 현재 영상 편집 지시가 있으면 그 영상의 지정 구간을 편집 후 확인하고 원본을 보존한다. 필요한 컷 전환은 자연스럽게 잇는다. 일괄 편집, 다른 콘텐츠와 권리 변경은 별도 범위다. AI 관찰, 사용자 지시, 실제 적용, 사용자 최종 확인, 명시적인 다음 지시를 각각 기록한다.
