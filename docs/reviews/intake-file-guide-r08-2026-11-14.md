## 실제 확인이 남은 한계

- iOS의 새 document-only 선택 창은 WebKit 소스·UTType 시험·브라우저 흉내로 확인했으며 실제 iPhone/iPad에서 메뉴가 사라졌는지는 미검증. 사용자 성공 영상은 기존 Files 경로의 물리적 증거다.
- Android는 기존 영상 필터를 유지해 갤러리/카메라가 열릴 수 있다. 모든 플랫폼을 파일 경로로 강제했다고 말하지 않는다.
- File 선택 경로는 카메라 원본의 출처 증명이 아니다. 형식·크기·fps·해시·같은 짝 검사는 유지했다. 실제 접수→관리자 다운로드 전 바이트 해시 비교는 미완료다.
- 제품 커밋·푸시·배포는 이 체크포인트 시점에 아직 하지 않았다. 맥 미니 실제 수신·전체 총괄 승인·운영 성공을 추정하지 않는다.
