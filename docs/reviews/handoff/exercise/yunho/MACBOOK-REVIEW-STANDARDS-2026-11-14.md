# 운동 영상 공통 검수 기준 — 사용자 확정

2026-11-14. 앞으로 모든 운동에 사용자가 이전에 요청·지적한 기준을 함께 적용한다. 기존 MACBOOK-GUIDE, checkpoint와 운동별 기록의 구체 지시도 계속 유효하다. 현재 운동 P022 무릎 꿇고 메디신볼 오버헤드 스로우; 사용자 다음 지시 전 이동하지 않는다.

1. 제목이 동작과 영상에 맞고 초보자가 이해할 수 있는지 확인한다. 낯선 말은 자세가 드러나는 쉬운 표현으로 바꾼다.
2. 영상 전체에서 시작과 끝, 반복의 연결, 멈춤·어색한 추가 횟수, 잘림, 다른 사람 노출, 실제 동작과 설명의 일치를 확인한다. 일부만 봤으면 범위와 미확인을 밝힌다. 직접 영상은 승인 범위 내 필요한 편집을 수행하며 기존 원본을 보존한다. 참고 영상과 직접 촬영본을 구분하고 촬영 필요를 남긴다.
3. 장비와 안전한 고정·공간·반발, 운동 부위, 강도, 난이도, 횟수·세트·휴식, 좌우 및 실제 수행 방법을 각각 확인한다. 몸통·발·손·방향 등 실제 영상에서 확인되는 사실과 불확실성을 구분한다.
4. 월볼처럼 직접 던지는 운동을 제외한 대부분의 파워 운동은 양쪽 수행을 기본으로 한다. 직접 던지기는 기존 투구 방향 지침과 개별 운동의 목적을 대조한다. 예외를 일괄적으로 확정하지 않는다.
5. 비슷한 정보는 같은 위치: 수행 순서와 장비 고정·공간·안전, 자세 무너짐에 따른 세트 중단과 통증 시 중단은 ‘이렇게 하세요’; 무게·저항·높이 등 강도 선택과 조절은 ‘강도’에 둔다.
6. ‘투수에게 왜 필요한가’는 어색한 표현이나 동작 반복에 그치지 않고 투구에 필요한 능력과 운동의 훈련 목적을 쉽고 정확하게 연결한다. 실제 연구가 뒷받침하지 않는 구속 향상·재활 단계·최적 처방 등은 단정하지 않는다. 관련 연구와 해당 동작 직접 증거의 차이를 밝힌다.
7. 사용자에게 보기 편하게 운동명과 상태, 수정 전→후 및 이유, 장비·부위·강도·난이도·횟수·세트·휴식, 영상에서 중점 확인할 점과 미확인 사항을 보고한다. 사용자 요청에 따라 가능한 내용 수정은 바로 저장하고 재확인한다. 다음 운동은 사용자가 지시할 때 이동한다.
8. 기본 무음 및 반복 재생을 지향한다. 운영 웹의 기본 무음 변경은 아직 배포되지 않았으므로 실제 영상이 소리 켜짐이면 수동 음소거한다. 재생 설정 확인은 영상 전체 편집 검수의 대체가 아니다.

이 문서 공유는 사용자 지시에 따른 검수 기준 전달이다. 맥 미니가 실제로 수신·이해했는지는 확인되지 않았다.
