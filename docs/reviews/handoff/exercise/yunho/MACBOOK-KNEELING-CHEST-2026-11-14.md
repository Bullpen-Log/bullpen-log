# 무릎 꿇고 메디신볼 체스트 패스 — 맥북 검수

2026-11-14. EX-Y-P-031, P030에서 사용자 다음 지시로 이동. 현재 운동에서 사용자 판단 대기.

- 제목 톨닐링 → 무릎 꿇고. ‘하체를 못 쓴다’ 단정을 서서 할 때 다리로 미는 동작을 줄인다는 설명으로 변경. 안전 공간·공 회수·균형과 속도 저하 시 세트 중단·통증 시 중단, 투수에게 필요한 상체 빠른 힘의 훈련 목적과 강도란에 공 무게 선택을 추가했다. 강도 중간→높음. 제목·설명·설정 저장 후 다시 열어 확인.
- 중급, 가슴·삼두·코어, 메디신볼, 3×5, 180초 유지. 양팔을 함께 사용하는 운동. 설정 수치가 최적이라는 근거는 확인되지 않음.
- 직접 촬영 영상 반복 재생. 시작 및 약 1초 장면에서 두 무릎을 꿇고 공을 가슴 앞에 잡는 자세를 확인했다. 전체 동작 및 영상 편집 검수는 미완료. 던지는 방향, 몸통 균형과 영상 시작·끝을 확인할 것.
- https://pubmed.ncbi.nlm.nih.gov/31856662/ 는 누워 메디신볼을 밀어 던지는 동작의 상체 파워를 다루는 간접 근거. 이 특정 자세의 훈련이 투구 구속을 높인다는 직접 증거가 아니다.
