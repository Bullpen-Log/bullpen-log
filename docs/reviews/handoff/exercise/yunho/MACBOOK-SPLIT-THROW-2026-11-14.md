# 스플릿 스탠스 스로우 (큰 공) — 맥북 검수

2026-11-14. 현재 EX-Y-P-019, 운동 ID 8ad883fc-49b9-4b6a-ab63-244e96abe433. 사용자 다음 지시 대기. 사용자 기준: 월볼처럼 직접 던지는 운동을 제외하면 대부분 파워 운동은 양쪽 수행. 이 운동은 직접 던지는 동작으로 기존 투구 방향 지침을 적용했다.

- 기존 좌우 각각 3×5 → 투구할 때와 같은 발이 앞인 자세로 3×5, 좌우 각각 해제. 설명의 발 위치도 명시. ‘세기’ → ‘강도’. 운영 화면에서 저장 후 운동을 닫고 다시 열어 모두 확인했다.
- 강도 중간, 난이도 초급, 장비 메디신볼, 목표 코어·고관절·전신, 90초 휴식 유지. 안전한 벽과 튀는 방향 안내 있음. 실제 부하·최적 횟수/휴식은 확인되지 않음.
- 유튜브 IaKpCClc3VE 참고 영상, 촬영 필요. 영상 열고 반복 켜짐 및 음소거 확인. 2초 부근 정지 장면만 확인했으며 전체 동작·편집 검수는 미완료. 영상 시범 및 설명 일치, 발 위치·투척 방향 재확인 필요.
- 근거 https://pubmed.ncbi.nlm.nih.gov/39074186/ 는 메디신볼 움직임과 투구의 하지 역학을 비교한 연구이며 동작 간 차이를 보여준다. 이 특정 운동의 구속 향상이나 처방의 최적성을 입증하지 않는다.
