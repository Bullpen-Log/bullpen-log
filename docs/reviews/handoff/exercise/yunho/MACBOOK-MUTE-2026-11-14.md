# 운동 영상 기본 음소거 — 맥북 인계

사용자 요청: 영상을 열 때 기본 음소거. 맥북에서 웹 유튜브 참고 영상 재생기를 준비 시 재생 전에 음소거하도록 `components/exercise-video/youtube-player.tsx`를 수정했다. 기존 직접 촬영 영상 웹 재생기는 이미 muted로 시작한다. 소리 켜기 조작은 유지했다.

현재 이 코드 변경은 맥북 작업 폴더에만 있고 커밋·운영 배포되지 않았다. 코드 검사(eslint, diff --check)는 통과했다. 로컬 개발 서버가 응답하지만 운동 라이브러리 접근은 로그인으로 이동하여 변경된 재생기의 실제 동작 및 소리 켜기 확인은 아직 못 했다. 네이티브 앱의 유튜브 영상 기본 음소거는 아직 적용하지 않았다. 맥 미니에서 수신·검토했다고 확인된 바 없다. 후속: 웹 실제 재생과 소리 전환 검증, 앱 범위 검토 및 담당 조율, 코드 독립 검수와 운영 배포 승인 확인.
