# 검수 완료 운동의 강도 안내 정리

사용자 지시: 어려운 톨닐링을 쉬운 말로 바꾸고, 지금까지 검수한 운동의 장비 무게·저항·높이 등 선택 안내를 강도로 모은 뒤 현재 운동으로 돌아올 것.

- P022 제목을 ‘톨닐링 메디신볼 오버헤드 스로우’ → ‘무릎 꿇고 메디신볼 오버헤드 스로우’로 저장하고 다시 찾아 열었다. 영상 반복 재생. 사용자 검토 및 전체 영상 검수 대기.
- P001~P022와 밴드 보조 플라이오 푸시업, 밴드 스피드 벤치 프레스의 설명을 운영 화면에서 확인했다. 그중 랜드마인 회전 펀치, 밴드 익스플로시브 힙 로테이션, 랜드마인 펀치, 스탠딩 케이블 익스플로시브 로테이션, 바벨 스피드 벤치 프레스, 싱글렉 박스 점프, 인클라인 플라이오 푸시업, 밴드 스피드 벤치 프레스, 스플릿 스탠스 스로우 (큰 공)의 무게·저항·높이 선택 안내를 강도로 옮기거나 정리했다. 각 운동을 닫고 다시 열어 설명 저장을 확인했다.
- 고정 장치·공간·밴드 손상 확인과 통증 및 위험 시 중단은 수행 방법에 유지했다. 공의 반발·바닥 적합성 같은 안전 선택은 수행 방법에 유지한다. 운동의 강도 수치나 처방을 일괄 변경하지 않았다. 미검수 운동 전체가 정리됐다고 간주하지 않는다.
