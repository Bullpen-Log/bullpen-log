# 김민 운동 영상 검수 반영 — 2026-11-13

워밍업·하체·상체·모빌리티 순차 검수에서 남아 있던 승인 사항 19건을 운영 라이브러리에 반영했다.

- 모빌리티 운동 15개의 설명을 갱신했다. 스플릿 스탠스 골반 회전과 밴드 힙 디스트랙션은 수행 방법에도 승인된 동작을 반영했다.
- 자체 영상 ‘흉추 모빌리티’를 ‘사이드라잉 윈드밀’로 바꿨다. 중복 참고 영상 ‘사이드라잉 윈드밀’과 ‘막대 흉추·광배 스트레치’는 일반 목록과 새 일정에서 숨겨 기존 기록을 보존했다.
- 워밍업 ‘A-스킵’의 앞뒤 대기 구간을 줄이고 화면 오른쪽에서 출발해 왼쪽에서 끝나도록 크롭했다. 1080p 원본 재생용과 720p H.264·HEVC 재생용, 썸네일을 갱신했다.
- 앱과 웹이 갱신된 라이브러리를 받도록 운동 캐시 버전을 올렸다. 검수 기록 원본과 변경 전 데이터는 로컬에 보관했다.
