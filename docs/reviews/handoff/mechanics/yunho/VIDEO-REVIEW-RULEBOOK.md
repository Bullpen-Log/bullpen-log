# 싱커 운동·투구 드릴 영상 검수 룰북

**제1판 · 2026-11-25 · 운동영상과 메커니즘 영상 공통**

이 책은 영상 검수 담당자가 매 영상의 준비, 설명 작성, 수정 확인, 사용자 검수, 인계에 적용하는 필수 규칙이다. 설명은 두 라이브러리에서 한 사람이 쓴 것처럼 같은 문체와 구조를 사용한다. 동작, 장비, 훈련 목적과 근거는 각 영상에서 확인한 내용으로 채운다.

## 제1장 적용과 우선순위

**제1조 최신 지시.** 사용자의 최신 공통 정정이 이전 공통 규칙보다 우선한다. 영상 하나에 관한 지시는 해당 영상에서 적용하며, 다른 영상에는 그 지시가 정한 범위만 공통 적용한다. 공통 지시가 추가되면 이 룰북과 인계 기록을 갱신하고 두 담당에게 공유한다. 사용자가 확정한 개별 제목, 동작 묘사, 편집 시점은 영상별 기록에 보존한다.

**제2조 공통 기준과 분야별 점검.** 운동영상과 투구 드릴 모두 제2~8장을 따른다. 운동은 장비·부하 기록과 운동별 처방, 드릴은 투구 구간과 목적 순서를 추가로 확인한다. 과거 문서에 남은 전체 검수 후 일괄 편집, 반복이 한 바퀴 끝날 때까지 기다리기, 모든 제목의 용어 풀이 지시는 최신 규칙으로 대체한다. 새 규칙은 이후 각 영상 차례에 적용한다. 이전 영상의 소급 점검이나 일괄 수정은 사용자가 정한 범위에서 한다.

## 제2장 한 편의 검수 순서

**제3조 재개.** 원격 검수 기록을 수신하고 담당 분야, 검수자, 현재 영상과 다음 후보, 사용자 지시 및 보류 항목을 확인한다. 운동·메커니즘과 검수자별 기록을 구분한다. 제목 대신 실제 항목 ID로 같은 이름과 공 크기 변형을 구별한다.

**제4조 관찰과 사전 수정.** 다음 순서로 한 편씩 진행한다.

1. **실제 재생.** 시작 자세, 본 동작, 반복과 장면 전환, 자연스러운 종료까지 확인한다. 얼굴·손발·장비 등 관찰에 필요한 부분이 가려지거나 잘리는지, 다른 사람이나 불필요한 장면이 보이는지 확인한다. 일부만 볼 수 있었다면 시점과 미확인 항목을 남긴다.
2. **영상·설명 대조.** 원본 제목의 의미, 실제 동작, 설명의 각 단계, 장비·강도·목적, 해당하는 수행 설정을 나란히 확인한다. 앞서 발견한 문제는 해당 영상 차례에 안내한다.
3. **근거 확인.** 제7장의 자료 기준을 적용한다. 각도나 자료가 불충분하면 확인 가능한 부분부터 보완하고, 판단이 남은 부분을 특정한다.
4. **사전 수정.** 영상과 근거로 명확한 제목·설명·분류·설정 및 자체 촬영 썸네일 수정은 기존 권한 범위에서 먼저 저장한다. 수정과 저장 확인은 코드로 한다. 항목 ID와 기존 값을 확인하고, 다른 변경이 들어왔으면 최신 값을 다시 읽어 필요한 부분만 수정한다.
5. **결과 확인.** 저장한 값을 다시 읽고, 실제 화면에서 새 제목·설명·줄 정렬과 영상이 맞게 표시되는지 확인한다. 저장 확인과 화면 표시 확인을 각각 기록한다. 이전 문구가 남은 화면은 새 설명을 표시했다고 보고하지 않는다.
6. **사용자 검수.** 오른쪽에 현재 영상 하나와 설명을 띄운다. 반복을 지원하면 켜짐을 확인하고 기본 무음을 적용한다. 반복이 끝날 때까지 기다릴 필요는 없다. 자동 반복, 경과 시간, 화면을 열었다는 사실로 다음 영상에 진입하지 않는다.

**제5조 사용자 판정.** 설명이나 편집 의견만 받으면 해당 영상에 반영·확인하고 현재 위치를 유지한다. ‘오케이’, ‘다음’처럼 명시적으로 이동하라는 말이 있을 때만 판정과 보류 사항을 적고 넘어간다. ‘수정하고 다음’은 수정과 재확인 뒤 이동한다. ‘보류하고 다음’은 보류 사유를 보존한다. ‘다시 보여줘’는 기존 기록을 유지하고 해당 영상으로 돌아간다. ‘오늘은 여기까지’는 현재 영상과 다음 행동을 저장한다. 재생 실패 시 현재 영상에서 재생 상태를 복구한다.

## 제3장 공통 설명 양식과 표준 문체

**제6조 표준 양식.** 공개용 한국어 설명은 다음 네 소제목을 이 순서와 표기로 쓴다. 아래 괄호는 작성자가 확인한 내용으로 바꾼다. 장비가 필요 없는 영상은 장비 문장을 생략하는 식으로 해당하는 내용만 채운다.

```text
■ 어떤 운동인가
   [시작 또는 핵심 동작]으로 [실제로 하는 동작]을 연습하는 [운동/드릴]입니다.

■ 이렇게 하세요
1. [시작 자세와 도구 배치]를 준비합니다.
   [필요한 공간 또는 고정 상태]를 확인합니다.

2. [어느 손·발을 어떻게 어느 방향으로 움직이는지] 적습니다.
   [같은 단계에서 동시에 일어나는 핵심 동작]을 필요할 때 이어 씁니다.

3. [착지·던지기·버티기·복귀 중 필요한 동작]을 이어갑니다.
   통증이 생기면 중단합니다.

■ 투수에게 왜 필요한가
   [투구 단계에서 필요한 움직임이나 능력]을 설명합니다.
   [이 운동이 그 움직임이나 능력을 어떤 방식으로 연습하게 하는지]를 설명합니다.

■ 강도
   [공·중량·저항·높이·이동 폭 등의 실제 선택 기준]을 적습니다.
   [동작이 흐트러질 때 줄일 항목과 목적별 강도]를 필요한 범위에서 적습니다.
```

**제7조 섹션별 작성 기준.**

| 위치 | 반드시 확인하는 내용 |
| --- | --- |
| 어떤 운동인가 | 영상의 핵심 동작을 보통 한 문장으로 요약한다. 이해에 꼭 필요한 어려운 야구 용어만 한 문장으로 푼다. 스위치 풋·힌지의 별도 풀이는 생략한다. 사용자가 설명을 요청한 서포티드 레그리프트 드리프트는 레그리프트가 다리를 드는 동작임을 짧게 밝히고 드리프트를 쉬운 말로 소개한다. |
| 이렇게 하세요 | 시작 → 실제 움직임 → 필요한 마무리 순서로 쓴다. 장비 배치·고정, 공간과 반발, 수행 중 위험이나 쉬어야 할 상황은 여기서 안내한다. 부하 선택과 강도 조절은 강도에 둔다. 통증 안내는 마지막 문장으로 통일한다. 균형 유지가 목표나 필요한 안전 기준일 때만 ‘균형을 잡습니다’를 쓴다. |
| 투수에게 왜 필요한가 | 투구에서 필요한 능력과 운동이 그 능력을 기르는 방식을 연결한다. 동작 순서를 다시 풀어쓰거나 ‘투구가 수월해집니다’로 끝내지 않는다. 왜 그 타이밍이 필요한지 명확히 쓴다. 앞에서 필요한 용어를 풀이했다면 여기서 같은 용어로 실제 투구와의 연결을 설명한다. 일률적인 구속 향상, 부상 예방, 재활 효과 표현을 피한다. |
| 강도 | 훈련 목적에 맞는 강도와 무게·저항·높이·거리·속도를 고르는 기준을 적는다. 처음부터 맨몸으로 하는 드릴에는 맨몸 동작의 범위나 속도로 강도를 안내한다. 공이 있어야 성립하는 드릴에는 공 없이 연습하라는 문구를 넣지 않는다. 동작 수정은 움직임을 확인할 수 있는 강도, 파워·구속 프로그램은 충분히 준비한 뒤 해당 프로그램에서 정한 강도로 안내한다. 실제 기록 기능이 있는 운동의 세트·횟수·유지 시간·휴식은 해당 처방 항목과 일치시킨다. |

**제8조 표준 문장과 단어.** 현재형 ‘~합니다’로 쓴다. 시작부터 끝까지 같은 발, 장비, 동작을 같은 이름으로 부른다. 짧고 평이한 동사를 쓰며 꼭 필요한 단서만 남긴다. 운동이나 드릴 목적과 무관한 준비 자세, 마무리, 참고 영상 소개를 습관적으로 덧붙이지 않는다.

| 상황 | 쓸 표현과 기준 |
| --- | --- |
| 소제목 | ‘세기’를 ‘강도’, ‘왜 하나요’·‘왜 필요한가’를 ‘투수에게 왜 필요한가’로 통일한다. |
| 도구 | ‘작은 메디신볼’, ‘큰 메디신볼’, ‘플라이오볼’, ‘야구공’을 확인된 종류대로 적는다. 작은 공과 가벼운 공은 별개의 특성이다. ‘케이블 머신’, ‘랜드마인 고정 장치’ 등 동일 장비 이름을 통일한다. |
| 준비 자세 | 발 간격을 정할 필요가 없는 경우 ‘편하게 섭니다.’를 쓴다. 드롭 스텝의 발 이동 폭을 근거 없이 ‘작게’ 고정하지 않는다. 몸을 짚는 곳은 기둥이 필수인 경우를 제외하고 ‘앞에 있는 벽이나 기둥을 짚습니다.’처럼 가능한 받침을 표현한다. |
| 박스에서 떨어지기 | 실제 몸이 공중으로 내려오는 시범은 ‘박스에서 바닥으로 떨어져 무릎을 굽히며 착지합니다.’처럼 쓴다. 실제로 한 발씩 올라가거나 내려오는 운동은 그 발과 순서를 명시한다. |
| 고관절·뒷다리 | ‘엉덩이를 접습니다’, ‘엉덩이만 뒤로 뺍니다’ 대신 영상에 보이는 무릎과 몸의 움직임을 적는다. 예를 들어 해당할 때 ‘오른발로 버티며 오른쪽 무릎을 굽혀 몸을 낮춥니다.’로 쓴다. 움직임과 회전에 초점을 두고 뒷발을 세게 밀거나 억지로 비틀라는 큐를 관성적으로 쓰지 않는다. |
| 체중 이동과 회전 | ‘체중을 옮기면서 골반과 몸통을 돌립니다.’처럼 짧게 쓴다. 내딛는 도중 회전이 시작되면 착지가 끝난 다음에 회전한다고 쓰지 않는다. 드리프트의 중심은 뒷발에 과하게 남지 않게 하면서 진행 방향으로 옮기는 흐름으로 설명한다. |
| 안전과 마무리 | 공을 던지는 운동에 필요한 경우 ‘던질 곳과 주변에 사람이 없는지 확인합니다.’를 준비 단계에 둔다. 통증 문구는 ‘통증이 생기면 중단합니다.’로 통일한다. 운동을 설명하는 데 필요한 자연스러운 마무리만 쓴다. |
| 메디신볼 무게 | 모든 메디신볼 운동과 드릴의 강도에 ‘[그 운동의 핵심 움직임]을 유지할 수 있는 무게의 메디신볼을 고릅니다.’를 넣는다. 예를 들어 착지와 던지기의 연결이 끊기거나 팔로 억지로 밀게 되면 가벼운 공으로 바꾸도록 적는다. 회전, 착지, 버티기 등 실제 목적에 맞춰 선택 기준을 쓴다. 근거로 확인한 적정 범위만 수치로 적는다. |

**제9조 문장과 화면 정렬.** 문장마다 마침표 뒤에서 반드시 줄을 바꾼다. 번호의 점과 소수점은 그대로 둔다. 번호 단계 사이에는 빈 줄 하나를 둔다. 단계 안에서 별개의 동작이 길어지면 번호를 나누고, 동시에 하는 동작은 같은 단계에서 ‘이때’, ‘~와 동시에’처럼 관계를 표시한다. 실제로 확인한 경우에만 ‘동시에’를 쓴다. 번호는 원래 왼쪽 위치에 두며 첫 문장 이후의 문장과 자동 줄바꿈은 번호 뒤 첫 글자에 맞춘다. ■ 아래의 일반 본문과 자동 줄바꿈은 ■ 뒤에 오는 제목의 첫 글자 위치에 맞춘다. 저장된 공백과 실제 화면 정렬을 구분한다. 긴 문장이 보이는 좁은 화면과 넓은 화면, 확인할 수 있는 앱 화면에서 적용 여부를 기록한다.

## 제4장 영상과 일치하는 동작 설명

**제10조 발, 방향, 시점, 횟수.** 목표를 기준으로 어느 발로 시작하고, 어디로 이동하며, 어느 발로 뛰고 착지하는지 써야 따라 할 수 있는 운동은 그 정보까지 적는다. 오른손 투수의 실제 시범을 기준으로 쓰고, 반대 방향이 적용되면 왼손 투수의 손발과 방향을 바꿔 안내한다. 시범에 반복이 있으면 왕복 횟수와 총 이동·점프 횟수를 구분한다. 시범 횟수와 사용자 처방은 별개다. 측면과 후면이 다르게 보이면 동작을 가장 명확히 보여 주는 구도로 확인하고, 사용자가 지정한 기준 구도가 있으면 그 구도를 따른다. 확인할 수 없는 착지 발과 순서는 미확인으로 남긴다.

**제11조 이전 사용자 정정을 적용하는 예.**

- 스텝백 스로우의 시범처럼 오른발을 딛는 순간 왼쪽 무릎을 올리고 바로 던지는 동작은 그 순서를 짧게 적는다. 발을 하나씩 멈춰 딛는 두 동작으로 나누지 않는다.
- 교차 스텝은 측면에서 확인한 첫 움직임과 교차 뒤 발의 방향을 설명한다. 사용자가 정한 기준과 기존 확인 내용을 영상별 기록에서 먼저 읽는다.
- 드롭 스텝 스로우는 목표에 등을 보인 시작 자세와 던지는 쪽 발이 실제로 어디로 옮겨지는지를 확인한다. ‘작게’ 같은 범위는 영상의 훈련 목적상 필요한 경우에만 쓴다.
- 워킹 와인드업은 걸어온 동작과 무릎 들기, 내딛기, 던지기가 바로 이어지도록 표현한다. ‘오래 멈추지 않습니다’처럼 중간 정지를 허용하는 듯한 문장은 피한다. 참고 영상의 시범 속도만으로 사용자 강도를 일률적으로 정하지 않는다.
- 드리프트를 연습하는 드릴은 중심이 목표 방향으로 이동하고 앞발 지지와 회전으로 이어지는 타이밍을 설명한다. 구속과의 관계를 설명할 때 목표 방향으로 이동하는 속도 하나를 구속의 결정 요인으로 단정하지 않는다.
- 박스 낙하 과제는 낙하, 착지, 투척을 구분한다. 어느 발로 떨어지고 딛는지 확인되지 않으면 그 부분을 먼저 검증한다. 영상에서 확인한 동작과 사용자 지시가 충돌해 보이면 시점과 구도를 기록해 확인한다.

## 제5장 제목·장비·목적 분류

**제12조 제목.** 제공자의 원래 동작과 실제 시범이 같은지 본다. 원문 확인이 필요하면 영어 제목을 별도로 확인하고, 한국어 제목은 같은 운동에 쓰는 용어와 공 크기를 통일한다. P1·P2·P3 등 제공자의 코드 번호는 운동과 드릴 제목에서 제거한다. 사용자가 정한 제목 ‘서포티드 레그리프트 드리프트’ 같은 고유 표기는 존중한다.

**제13조 필수 장비와 운동별 기록.** 실제 장비와 등록 장비를 대조한다. 지지용 기둥·박스·벤치, 저항을 주는 중량, 두 가지 장비가 모두 필요한 경우, 대체 가능한 경우를 구분한다. 스텝박스와 점프용 박스는 목적·높이·안정성으로 나눈다. 운동영상은 실제 지원되는 부위·난이도·강도·세트·횟수·유지 시간·휴식·좌우와 기록용 무게 기준을 확인한다. 덤벨 한 개와 양손 각각의 무게, 바벨 전체 무게, 몸에 더한 중량, 케이블 표시 설정을 구분한다. 밴드는 저항·보조·미확인을 나누고 색을 같은 강도나 kg으로 환산하지 않는다. 1RM이나 볼륨·최고 기록 비교는 해당 운동과 기록 방식이 지원할 때 적용한다. 실제 기록과 설정된 목표를 구분한다. 메커니즘은 해당 화면에서 확인되는 단계·장비·목적·강도를 기준으로 검수한다.

**제14조 훈련 목적의 순위.** 사용자에게 이 운동을 추천할 이유에 해당하는 목적을 개수 제한 없이 선택하고, 가장 중요한 목적부터 순서를 정한다. 같은 동작 안에서 함께 나타난 일반 동작은 보조 목적에 자동으로 넣지 않는다. ‘스로잉’은 팔 동작 교정이나 던지는 속도 자체가 훈련 목표인 경우에만 선택한다. 드리프트나 드롭이 끝난 뒤 구간을 연습하는 힌지 홉 스로우 작은 공 영상은 사용자의 지시대로 몸통 회전을 중점으로 한다. 같은 이름의 작은 공·큰 공 영상도 실제 시범에 따라 목적·순위·단계·장비를 각각 관리한다. 추천은 실제 변형의 해당 목적·우선순위와 단계·장비 조건을 함께 사용한다. 한 변형에 맞는 목적과 추천 순위를 다른 변형에 복사하지 않는다.

**제15조 과제별 보완.** 대부분의 파워 운동은 양쪽 수행을 기본으로 검토하고, 벽에 공을 던지는 운동 등은 투구 방향과 개별 목적을 확인한다. 플라이오메트릭은 착지를 익히는 기초 과제와 빠른 반응을 연습하는 과제를 구분해 그 운동이 투구에 어떻게 이어질 수 있는지 설명한다. 아이소메트릭은 자세를 크게 바꾸지 않고 힘을 주는 운동이라는 뜻을 짧게 밝힌다. 실제 힘의 방향, 자세, 호흡, 유지 시간과 노력을 확인하고 같은 시간이나 강도를 모든 운동에 강요하지 않는다. 근육과 힘줄 관련 설명은 해당 과제와 근거가 뒷받침하는 만큼만 쓴다.

## 제6장 촬영·영상 편집·썸네일

**제16조 출처와 촬영 필요.** 직접 촬영 영상 있음 / 참고 영상만 있음 / 영상 없음 / 출처 미확인으로 나눈다. 직접 촬영본이 없다고 확인된 항목은 담당 촬영 필요 목록에 누적한다. 참고 영상과 영상 자체가 없는 경우를 구분한다. 자체 촬영본의 재촬영은 가려진 핵심 신체 부위, 시범과 설명의 불일치 등 근거와 함께 별도로 기록한다. 촬영에 필요한 실제 공 종류와 받침 등 장비를 누락하지 않는다.

**제17조 편집.** 사용자가 편집을 요청하면 현재 영상에서 바로 작업하고 결과를 확인한다. 원본과 기존 편집본을 보존한다. 각도 전환을 편집할 때는 필요하면 자연스러운 전환 효과를 적용한다. 앞뒤 발이나 공이 가려지거나 동작이 빠지는지 확인한다. 마지막은 실제 동작의 마무리를 남기고 대기, 시선 돌림, 과제와 관계없는 추가 움직임을 덜어낸다. 사용자가 구체적인 끝 장면을 지정하면 그 순간을 기준으로 편집한다. 버티기·느린 내리기·캐리의 운동 구간은 보존한다. 변경한 시간대와 재생으로 확인한 범위를 기록한다.

**제18조 대표 이미지.** 자체 촬영본은 실제 시범 프레임 중 자세·도구·핵심 신체 부위가 함께 보이는 장면을 고른다. 준비 자세보다 운동을 대표하는 장면을 우선하고, 필요한 부위와 장비를 남긴 채 화면비를 유지한다. 권한 범위 안에서 직접 수정하고 새 이미지가 실제 화면에 보이는지 확인한다. 기존 이미지와 영상 원본을 보존한다. YouTube 등 참고 영상은 제공자 이미지를 유지하고 촬영 필요 여부를 기록한다.

## 제7장 근거와 적용 범위

**제19조 자료 조사.** 메커니즘 설명을 새로 쓰거나 변경하기 전에 드라이브라인 공식 공개 자료를 실제로 열어 읽고 시범과 대조한다. 트레드의 주장을 쓸 때는 트레드 원자료도 확인한다. 운동과 드릴의 주장에 맞는 국내외 원저·체계적 문헌고찰·공식 학회 자료를 확인한다. 보고서에는 사용한 자료, 확인일과 읽은 범위, 실제 적용 문장, 대상과 부하, 직접 근거인지 유사 동작의 간접 근거인지, 적용 한계를 기록한다. 검색 결과만 본 자료, 개인 코칭 사례, 일반 훈련 원리와 해당 운동 효과 검증을 구분한다. 근거가 모자라면 확인된 연습 목적까지만 설명한다. 드리프트와 구속 관계는 단순 이동 속도, 드리프트의 타이밍과 이후 회전, 실제 구속 관련성을 구분하고 해당 설명에 쓰인 자료 범위까지 밝힌다.

**제20조 내용과 근거 기록.** 연령·훈련 수준·장비와 부하, 즉시 효과와 장기 효과, 일반 파워와 실제 투구로의 전이를 구분한다. 권리·효능·안전·번역 쟁점은 한국·미국·일본별로 필요한 확인을 기록하고 국가별 차이를 만들 때는 그 근거를 남긴다. 실제 사용한 출처의 중앙 기록은 운영 준비와 계정이 확인된 경우 저장소의 근거 등록 절차를 따른다. 검수 기록 공유, 등록 대기, 중앙 등록 확인을 각각 관리한다.

## 제8장 영상별 판정표와 보고 양식

**제21조 필수 점검표.** 내부 검수 기록에 각 항목을 **확인 / 수정 후 확인 / 확인 필요 / 해당 없음** 중 하나로 남긴다. 적용되는 항목을 빠뜨리지 않는다. 확인이 남은 항목에는 실제로 본 범위와 남은 이유를 적는다.

| 확인 항목 | 통과 기준 |
| --- | --- |
| 식별과 재생 | 영상 번호·실제 항목 ID·제목·출처·버전이 일치하고 현재 영상이 실제 재생된다. 반복·음소거는 해당 플레이어에서 확인한다. |
| 제목·촬영·편집 | 시범 동작과 제목이 일치하고 제공자 번호가 빠져 있다. 시작·주요 장면·끝·잘림·불필요한 구간을 확인하고 촬영 상태와 대표 이미지를 기록했다. |
| 따라 하기 | 처음 보는 사람이 어느 발이나 손을 어느 방향으로 움직일지 이해할 수 있다. 시점과 횟수 및 마무리가 화면과 맞고 안전 문구 위치가 맞다. |
| 한 사람의 문체 | 공통 네 소제목·표준 용어·‘~합니다’ 문체·문장별 줄바꿈·번호 사이 빈 줄·자동 줄바꿈 정렬이 맞다. 필요한 용어만 풀었고 반복 설명을 지웠다. |
| 목적과 강도 | 왜 필요한가가 실제 투구와 연결된다. 목적의 우선순위와 장비·부하가 시범에 맞고, 메디신볼에는 무게 선택 지침이 있다. |
| 근거와 저장 | 실제 사용 근거와 한계가 남아 있고, 수정한 내용은 저장값과 화면에서 확인했다. 남은 판단과 확인 범위는 구분했다. |
| 사용자 판정과 인계 | 요청 원문과 AI 관찰·제안을 구분했다. 승인된 이동만 기록했다. 이 영상의 촬영·편집 메모와 다음 행동을 남겼다. |

**제22조 사용자에게 보여주는 순서.**

1. **현재 번호와 제목.** 자체 촬영·참고·없음과 촬영 필요 여부를 한 줄로 적는다.
2. **이번에 반영한 내용.** 바뀐 문구나 분류, 영상 시간대를 이전과 비교하고 이유를 짧게 적는다. 이전 세션에서 적용한 것과 이번 수정, 추가 후보를 구분한다.
3. **직접 확인할 부분.** 실제 화면에서 볼 순서로 핵심 장면을 적는다. 예를 들어 ‘시작 자세 → 착지 발과 방향 → 회전과 던지기 → 끝부분’에서 이 영상에 해당하는 항목과 시점을 안내한다. 불확실한 점은 이때 함께 보여준다.
4. **근거·확인 범위.** 수정에 영향을 준 근거의 링크와 적용 범위, 저장·화면·재생 중 확인한 부분을 간단히 전한다.

**제23조 최종 정리와 교대.** 전체 검수가 끝나면 사용자에게 영상 확인 순서, 영상마다 중점으로 볼 장면, 완료·보류·미재생, 수정 전후와 반영 여부, 편집 시간대, 촬영·재촬영 및 준비 도구, 담당자 검토가 필요한 쟁점을 제공한다. 각 판정·수정 요청·종료 시점에는 다음 담당자가 이어볼 수 있도록 현재 영상, 실제 확인 범위, 다음 영상, 사용자 판단, 보류 사항을 저장하고 비민감 기록을 승인된 경로로 공유한다. 계정, 비공개 주소, 영상 원본은 공유 기록에서 제외한다. 원격 공유, 받는 기기의 수신, 실제 재생과 검수는 확인된 수준대로 구분한다.


## 사용자 추가 지시 · 2026-11-25

- 지시의 표면적인 단어만 고치는 데 그치지 않고, 사용자가 왜 그 표현을 고치라고 했는지 파악해 모든 해당 설명에 적용한다. 처음 읽는 사용자가 실제로 어느 발을 움직이는지 알 수 있어야 하므로 어떤 운동인가에도 동작 이해에 중요한 착지 발을 명시한다. 오른손 투수 기준과 왼손 투수의 반대 방향을 명확히 한다.
- 투구 중 목표 쪽 이동을 설명할 때 뒷다리로 몸을 밀어 전진시키는 큐를 중심으로 쓰지 않는다. 목표 방향으로의 이동 흐름과 골반·몸통 회전이 이어지는 타이밍을 설명한다. 지면반력의 존재를 부정하는 물리학적 주장으로 확대하지 않는다.
- 훈련 목적의 사용자 표시 용어는 상하체 분리 → 세퍼레이션, 몸통 회전 → 로테이션, 브레이크 → 블록이다. 기존 저장값과 추천 연결을 보존하는 시스템 변경 및 적용 여부를 확인한다.
