# 기록이 비는 사회인 묶음 — 고치기 계획 (초안, 승인 전)

> 근거: `docs/qa/2026-10-16-beta-100-weighted.md` 2절 1~9위 · 12위. 실제 투수 인구 100명 중 80명이 주 1회 던지는 사회인이다.
> 이 사람들은 매일 체크인하지 않고, 끼니를 안 적고, 안 던진 날을 남기지 않는다.
> 원칙 하나: **기록이 없는 날은 앱이 이미 '안 던진 날'로 센다.** 그러니 그 빈 날을 두고 잔소리하거나 틀린 숫자를 보이지 않는다.

## 하지 않는 것 (이번 범위 밖)

- 부하 지수 계산식 자체(하루 단위 지수 평균 → 7일 합) 바꾸기 — 트레이닝 · 암케어 · 프로그램이 같은 값을 읽어 영향이 크다. ⑦-③으로 표시만 다룬다.
- 체크인 없이 운동 일정 만들기(9-23 결정) · 장비 매일 꺼짐(의도) — 사용자 결정이 먼저.

## 사용자가 정할 것

1. 3번 — A(실제 공 수) / B(단위만 '부하')
2. 4번 — A(질문 하나 더) / B(엔진에서 빨리 걷기)
3. 7번 ③ 주 1회 리듬 규칙 — 넣기 / 빼기
4. 4번은 투구 첫 설정 화면(금윤호 영역)이다 — 이 세션에서 고치고 HANDOFF로 알릴지

## 확인 방법

- 바꾼 파일마다 tsc · eslint
- 시험: `arm-status:test` · `highlights:test` · `nutrition:test` · `training:test`(실패 20개가 고치기 전과 같아야 함)

- 화면은 로그인이 필요해 직접 못 봄 — 사용자 폰 확인 필요
